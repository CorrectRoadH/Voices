# 价格管理边界

所有用户包括管理员都不能手动管理价格。POST /api/v1/admin/stt/prices 保留为明确拒绝入口，沿用认证、管理员、CSRF 和恢复模式中间件，通过校验后返回 403 manual_pricing_disabled；不解析业务输入、不访问幂等缓存、不写价格或审计。GET 仍为管理员历史价格只读查询。

前端移除价格管理组件和导航，旧价格与 STT 调用地址在管理员路由守卫后重定向到 `/admin/calls?view=stt-costs`。费用与请求记录共用“调用日志”入口，仍分别读取已有费用快照与外部调用记录。不修改数据库结构或历史快照，已有价格查找规则保留；没有参考价继续显示未定价。上游自动价格同步不属于当前产品能力，不能把手填历史价格声称为新获取的供应商报价。

验证包含有无幂等键、历史成功键、非法输入、并发、普通用户、匿名和恢复模式，以及历史费用、只读分页、价格不可变与真实浏览器旧地址重定向。
