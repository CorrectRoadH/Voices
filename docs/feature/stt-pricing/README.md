# STT 时长估算费用

管理员在服务器管理查看真实提交的音频时长与参考费用，按时间、账号、服务商、模型和状态筛选。
每次真实提交意图锁定价格快照；轮询、恢复与本地重试不重复记费，明确重转创建新记录。

价格按 USD 微元保存，只有参考时长估算，不代表服务商实际账单。
未定价独立计数，结果待确认不能算成已完成或零费用。
删除录音后保留不含内容的运维快照。普通用户不能读取这些管理数据。
本功能遵守[用户控制](../../taste.md#t-1)与[应用无状态](../../taste.md#t-4)原则。
