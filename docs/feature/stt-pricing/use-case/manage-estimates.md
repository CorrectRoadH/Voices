# 查看 STT 费用

## 用户目标与起始状态

管理员希望查看全站转写提交的估算成本，价格由系统维护，用户不能手动配置。

## 完整路径

1. 管理员进入“调用日志”的“STT 费用”页签，按时间、账号、服务商、模型及状态筛选，查看列表和同范围汇总。列表倒序加载更多，汇总包含整个筛选范围。 {#inspect}
2. 每条显示账号当前邮箱、提交时间、服务商、模型、音频时长、提交确认状态、结果状态、失败次数、关联 ID、价格版本及估算费用，不提供业务内容链接。 {#metadata}
3. 不提供“模型价格”管理页面；旧价格与 STT 调用地址转到“调用日志”的“STT 费用”页签。任何用户包括管理员都不能手动追加、修改或删除价格。 {#price}
4. 后续真实提交使用新快照；历史提交费用不变。无适用参考价显示“未定价”。录音删除后关联 ID 可为空，费用快照保留。 {#snapshot}

## 结果与异常

界面明确提示“按音频时长估算，实际账单以服务商为准”。
汇总区分提交数量、已完成时长与估算费用、进行中估算费用、结果待确认和未定价数量。
汇总与记录使用单层布局，时长显示为时分秒，不要求用户换算毫秒。已完成与进行中估算费用标明只含已定价记录；未定价数量独立可见，不将部分已知费用声称为全部费用。记录的关联 ID 直接显示并允许选择复制。
极小金额保留微元，聚合先加微元再展示；不同确认状态分别统计。

普通用户返回 403，匿名返回 401，降级管理员的旧会话不能继续读取。
恢复模式允许查询。历史价格和费用快照只读保留；旧写价 API 经过现有认证与 CSRF 校验后返回禁止，不能通过旧幂等键重放成功。
不返回录音标题、文件名、正文、音频、凭据或原始服务商响应。

筛选无结果、加载、失败、刷新与加载更多有明确反馈。
中文、英文与窄屏可用，不让关联 ID 撑宽页面。

## 验收

通过真实 PostgreSQL 与 HTTP 入口验证真实提交、恢复复用、明确重转、删除保留、价格不可重算、权限、筛选及分页。
验证整数金额边界、缺价与结果不明汇总、手动写入拒绝与无副作用。
浏览器检查管理员查看筛选、旧价格页面重定向及窄屏；外部服务使用适配器边界 fake。
