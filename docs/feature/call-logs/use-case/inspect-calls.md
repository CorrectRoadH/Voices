# 查看个人及全站外部调用

## 目标与路径

用户进入“处理任务”，在“处理任务”与“调用日志”间切换。任务卡提供“查看调用记录”，以 job_id 筛选同一任务的请求；AI 生成记录可在个人调用记录中按类型/转写 ID 查找。页面提示调用记录永久保存，且仅包括启用后记录。

管理员在服务器管理进入“调用日志”，查看全站请求；可输入账号关键词（当前邮箱、用户名、显示名）、选择转写或 AI、操作、服务商、状态、填写模型 ID 与起止时间。筛选会清除旧分页，列表从最新记录开始；可继续加载。个人页不提供跨账号筛选。

每项显示调用时间、操作、模型、请求状态和已知 HTTP 状态；展开详情查看调用 ID、任务/转写/生成/操作 ID、是否进入网络发送、耗时、音频时长、token 用量及受控错误原因。未知值使用明确占位，不能伪造为零。成功轮询只表示查询成功，其所属任务仍可能处理中。

管理员的跨账号记录不链接录音正文或提供重试按钮；个人关联入口仅指向本人当前仍存在且未删除的录音/任务。删除录音后仍能看到调用元数据，链接不再提供。

## 异常与验收

无记录、查询失败、加载中、非法日期及加载更多分别提供可理解状态；刷新重新获取当前筛选的第一页。管理员被降级或账号停用后，旧会话不能继续读取管理端记录。更换个人筛选不能观察其他用户数据。恢复模式允许查询，不能通过调用日志触发外部请求。

支持中文与英文、深色与窄屏，调用 ID 等长值不能撑宽页面。正常操作使用中文自然语言 E2E，直接越权、隐私泄漏、崩溃、租约、删除及边界分页由必要的集成测试验证。

## 契约来源

[统一外部调用记录](../README.md) · [架构与生命周期](../architecture.md)

同一筛选下刷新保留现有记录，刷新按钮显示加载状态；加载更多只在分页按钮显示加载状态，失败保留已展示记录及重试入口。切换筛选或个人/全站范围时清空原列表，避免旧内容混入新范围。调用与任务、用量与费用的区别收纳在“关于调用记录”中，仍可随时展开查看。
