# 站点运行状态与日志

管理员通过站点概览查看数据库探测、账号数量、任务状态统计、待清理异常和存储用量，以及当前响应实例运行时间与资源限制。计数来自数据库，不使用占位数字；查询失败明确提示，不显示成功状态。

系统日志分为长期管理审计和最近 7 天运行异常。管理审计显示已有账号、注册开关、服务器配置、密码重置和 CLI 任务核对事件，支持动作与时间筛选及分页。运行异常支持类型、请求 ID 和时间筛选，记录 HTTP 5xx 及后台已知错误的安全分类，可用于关联用户报错中的请求 ID。

仅管理员可读取；不开放其他账号录音、转写或任务操作权限。日志不含密码、密钥、cookie、原始请求/响应、音频和转写正文。管理审计与管理写入同事务；运行异常为尽力记录，数据库故障或高负载可能缺失，不能代替容器日志。运行异常定期清理，审计不自动删除。

账号管理支持邮箱、用户名、显示名称搜索和角色、启停状态筛选，保留最后管理员保护、CSRF 和恢复模式约束。所有新界面复用 shadcn/ui + Tailwind 语义颜色，支持深色和窄屏。
