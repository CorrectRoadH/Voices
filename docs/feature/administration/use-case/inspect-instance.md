# 查看站点运行状态与日志

管理员进入“站点概览”，查看数据库连通性、当前实例运行时间、账号与任务状态、blob 用量和清理失败数量，手动刷新取得新快照。数据库故障时明确失败，不以 0 代替未知数据；存在失败或待核对任务时提示关注，不能宣称后台工作全部健康。

管理员进入“系统日志”，可切换管理审计与运行异常，通过类型、起止日期及请求 ID 缩小范围，逐页查看记录。切换筛选或刷新后回首屏，不把筛选失败误报成空日志。配置写入后可查到操作者、时间及修改字段名，不包含配置秘密值。

运行异常在重启/多实例后从 PostgreSQL 读取，超过 7 天不再展示；清理不能删除管理审计。并发新记录不使 keyset 翻页重复。错误分类和路由为受控数据，不透传不安全的错误文本或 URL。

管理员可在账号管理搜索用户并按状态、角色筛选，随后执行既有管理动作。普通用户没有新导航入口，直接调用管理 API 返回 403，匿名请求返回 401。管理员仍不能通过日志或概览访问他人的录音、人物与转写内容。

验收包含真实 HTTP、PostgreSQL、浏览器桌面/手机和深色场景，检查异常记录失败时原请求结果仍正确、资源超时受控、后台清理在恢复模式下可停止且不触碰业务内容。
