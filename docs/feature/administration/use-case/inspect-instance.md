# 查看站点运行状态与日志

## 用户目标与起始状态

管理员希望了解当前实例运行情况并查找安全诊断；统计和日志不授予他人录音、人物或正文的访问权。

## 完整路径

1. 管理员进入“站点概览”，查看数据库连通性、当前实例运行时间、账号与任务状态、blob 用量和清理失败数量，手动刷新取得新快照。数据库故障时明确失败，不以 0 代替未知数据；存在失败或待核对任务时提示关注，不能宣称后台工作全部健康。 {#overview}
2. 管理员进入“系统日志”，可切换管理审计与运行日志，通过类型、起止日期及请求 ID 缩小范围，逐页查看记录。切换筛选或刷新后回首屏，不把筛选失败误报成空日志。配置写入后可查到操作者、时间及修改字段名，不包含配置秘密值。 {#logs}
3. 管理员可在账号管理搜索用户并按状态、角色筛选，随后执行既有管理动作。普通用户没有新导航入口，直接调用管理 API 返回 403，匿名请求返回 401。管理员仍不能通过日志或概览访问他人的录音、人物与转写内容。 {#accounts}

## 结果与异常

运行日志跨重启、跨实例可读，超过七天不展示，管理审计长期保留。并发新增记录不使后续翻页重复；错误分类与路由不透传原始文本或 URL。

任务失败数包含服务商受理结果不明的失败尝试，与任务页一致。声纹处理在运行日志显示开始、建立样本、无合格样本和安全失败原因；只有当前任务成功发布才记录完成，不伪造历史补录。声纹不计入外部 STT/AI 调用。

验收通过真实 HTTP、数据库与浏览器检查快照、筛选分页、权限和脱敏。日志记录失败不能改变原请求结果，清理不能删除审计或业务内容，恢复模式下清理仍可正常退出。
