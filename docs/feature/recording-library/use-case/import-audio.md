# 拖入并保存录音

## 用户目标与起始状态

用户已登录并选择默认服务商与语言，希望保存多个日常录音。网页导入自动转写并区分说话人；站点已配置 LLM 时，转写成功后自动生成摘要和目录，无需额外开关。上传入口说明自动发送音频和转写文本及可能产生的费用。

## 完整路径

1. 拖入多个音频或使用文件选择器。导入选项默认收起，可按批次调整并逐条覆盖；自动检测语言时不显示语言代码输入。 {#select}
2. 逐文件查看上传进度与校验结果。有效文件分别入库，损坏文件显示原因且不产生转写费用。上传失败保留逐文件原因和幂等键，可重试；主动取消或离开导致的中止不弹错误通知。 {#upload}
3. 全部文件成功保存后，弹窗自动关闭并刷新录音库，后台转写继续。仍有失败或未上传文件时保留弹窗。 {#continue}
4. 打开已保存录音播放或查看后台进度，刷新后录音仍保留。转写成功后内置声纹能力继续匹配已标识人物，无需服务开关；已配置 LLM 时查看自动生成的摘要和目录状态，生成失败不影响转写阅读。 {#read}

## 结果与异常

再次或并发导入相同内容返回已有录音，不重复发起自动转写。中断可整文件重传，不提供断点续传；未发布的上传数据可回收。

上传或文件校验失败时，错误 toast 标识具体文件；依赖的人物、服务商或默认设置加载失败时分别显示原因与重试入口。声纹失败不影响转写、播放或人工关联。

验收以两个有效文件和一个损坏文件检查独立结果、失败重传、重复导入、弹窗关闭条件及刷新后播放。
