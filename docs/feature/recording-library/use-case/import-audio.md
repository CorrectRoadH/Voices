# 拖入并保存录音

Given 用户已登录，选择默认服务商与语言；网页导入后自动转写并区分说话人，无需另行确认发送。

When 拖入两个有效音频和一个损坏文件。

Then 有效文件分别入库并可播放；损坏文件提供原因且不产生转写费用，刷新后结果保留。

再次导入相同内容返回已有录音；并发相同导入也只保留一份。上传中断的临时文件可回收。

全部文件成功保存后自动关闭导入弹窗并刷新录音库，后台转写继续运行；存在失败或尚未上传文件时保持弹窗，允许原幂等键重试。导入默认收起模型等转写选项，自动检测语言时不显示语言代码输入。
