# 修改录音信息与校准开始时间

## 用户目标与起始状态

用户已打开自己的录音，希望修正标题、备注或录制开始时间。无法可靠读取录制时间的录音以导入时间代替，并提示待校准。

## 完整路径

1. 点击页首标题，或在录音信息中点击开始时间、备注，进入对应字段的原位编辑。只显示该字段的保存和取消操作，自动聚焦。 {#edit}
2. 按浏览器本地时区将开始时间校准到秒，或修改标题、备注；保存只提交实际变化字段。未改时间时保留原精度及来源。 {#save}
3. 读取校准后的消息时刻：开始时间加片段偏移决定时刻，跨本地日期显示分隔。播放图标悬停显示真实时刻及音频偏移；片段偏移、当前播放位置和转写版本保持不变。 {#verify-time}

## 结果与异常

Escape 取消。保存失败保留输入；修订冲突时，只有待修改字段与开始编辑时仍相同才自动使用最新修订重试一次。同字段冲突要求用户核对，不能覆盖他人的修改。

切换侧栏页签、关闭再打开录音信息保留草稿。原文件名、时长和大小只读；删除入口位于录音信息内并要求确认。没有片段时间时仍可校准录音开始时间，系统不补造片段时间。

验收核对本地时区、秒级校准、跨日、未修改字段保护、冲突重试及播放器稳定。
