# 录音库与导入

## 目标

用户将日常录音拖入浏览器后，在自己的服务器长期保存、播放和查找。

## 行为

- 支持拖入多个文件和文件选择器；逐文件显示上传进度、校验结果和失败原因。
- 支持 MP3、M4A、WAV、FLAC、OGG、WebM 音频；以服务端探测结果为准，拒绝损坏或无音轨文件。
- 默认单文件上限 2 GiB，可配置；流式上传，不将整个文件装入内存。初版失败后重传，不承诺断点续传。
- 原始文件保持不变；生成浏览器可播放副本。按内容摘要提示重复导入，返回已有录音。
- 录音有标题、录制时间、备注。无法可靠读取录制时间时使用导入时间并明确标记来源，允许用户纠正。
- 录音列表按日期排列，支持日期、状态、人物筛选和文本搜索；进入详情可播放和跳到发言片段。
- 删除录音需界面确认，立即停止展示，再后台清理数据库音频块和已知服务商资源；显示待清理或失败状态。

录音标题、录制时间与备注在详情页右侧的录音信息区域内编辑。保存仅提交修改字段；版本冲突时，若这些字段与开始编辑时相同，使用最新版本重试一次；同字段冲突保留输入并提示核对，不覆盖他人修改。未改时间时保留原精度和来源。

## 边界

初版不包括实时录音、公开分享链接、团队协作、自动摘要及无限长音频切片。

## 验收

以真实浏览器完成多文件拖入、失败重传、重复导入、刷新后播放及删除后不可访问。

录音列表显示当前激活版本中片段关联的普通人物，按人物 ID 去重；不包含内置分类、仅历史版本关联和未实际出现在片段中的标签。

录音详情的标题、起始时间与备注集中在录音信息区域；原文件名、时长与大小只读显示。正文不重复展示 metadata 表单。窄屏信息区域排列在正文之后，编辑入口滚动定位到该区域。
