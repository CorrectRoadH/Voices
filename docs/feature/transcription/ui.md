# 转写阅读与任务界面

布局与交互服务于[阅读转写](use-case/read-transcript.md)、[校对片段](use-case/edit-transcript.md)、[正文搜索](use-case/search-transcript.md)和[处理失败任务](use-case/recover-task.md)。通用反馈遵循[全站交互](../interface-interactions/ui.md)。

## 处理状态与阅读布局

尚无可阅读正文时，页面以标题、单一处理阶段和任务入口呈现；后台任务不使用持续骨架，也不重复显示顶部状态徽标和阶段说明。预处理提示完成后自动转写、允许离开；上传、提交、等待结果和整理结果直接更新同一状态行。

处理失败时在同一错误区域直接展示可理解的具体原因，没有具体原因时给出任务详情入口；不重复通用报错和同一任务原因，允许的重试或重新转写操作保持可见。

目录和摘要仅在当前版本可阅读后显示；未就绪时不展示它们的页签、空态和播放器目录入口。录音信息通过页首入口查看，关闭再打开保留编辑草稿；删除放在录音信息内。首次处理不在正文提供版本导出入口，历史成功版本仍可直接打开。音频就绪即显示播放器；后台生成新版本时保留正在阅读的旧正文及播放器。

## 消息与操作菜单

聊天正文按群聊显示，本人消息靠右、其他人物消息靠左，使用官方 Message 与 Bubble。桌面消息区居中且最大约 900px，气泡最大约 600px 且不超过消息区的 80%；手机自适应宽度。连续同一人物、相邻序号且同日的片段构成发言组，组内间距 4px、换组 12px；仍逐句保留播放、编辑和引用边界。

他人姓名仅在组首显示、头像仅在组尾显示，本人不重复显示姓名和头像。通过消息菜单更换人物时，仍提供可定位的选择弹层。日期用 Marker。本人气泡使用官方 tinted variant，他人用 secondary；圆角与主题沿用官方组件，不绘制额外尖角。

录音内时间、播放图标、校正标记及更多操作组成气泡内部紧凑底栏，不在每句下方另占工具栏。播放时间常驻；桌面有鼠标时更多按钮在消息悬停、键盘聚焦或菜单展开时显示，隐藏时不改变布局。触屏更多按钮始终可见，也支持长按菜单；键盘可聚焦打开。时间表示录音位置，不显示消息发送或已读状态。

消息菜单由官方 ContextMenu 处理右键与长按，更多按钮使用 DropdownMenu；支持播放本句、复制文字、复制引用、链接、多选、编辑及批量关联说话人。触摸取消和手势阈值由组件管理，不另写计时器。输入框内保留系统选择与编辑菜单；菜单关闭恢复焦点，正文轻点不进入编辑。

原位编辑使用官方 Input / Textarea 与 Button，保留原文字草稿和既有保存、取消快捷键。人物选择项显示官方 Avatar 与姓名。

## 播放器、侧栏与定位

录音播放器固定在窗口底部，向下滚动正文时仍能播放、暂停与拖动音频进度；页面底部预留空间，目录跳转不自动播放，不重建播放器。桌面右侧提供位置固定的 AI 主题目录；移动端通过播放器上的目录按钮打开。目录行为遵循[摘要与主题目录](../insights/README.md)：未配置 LLM 时显示配置提示，不按分钟抽取原文生成目录。

阅读页以聊天正文为主，右侧目录和录音信息保持紧凑；版本导出和人物工具默认折叠。播放器采用底部紧凑横条，手机采用两行布局。

桌面右栏用目录、摘要和录音信息三个页签分离导航、摘要阅读与管理，页签固定、内容区单层滚动；切换页签保留未保存的录音编辑草稿。当前激活状态使用标记展示，仅非激活版本提供激活操作。

正文上方不显示“转写文字”标题、新建转写、版本选择或模型状态。版本选择、状态、新建、激活与导出集中在“录音信息”的“版本与导出”中处理，默认折叠；说话人管理与内置人物片段显示控制集中在“录音信息”的“说话人与人物”中，正文直接呈现聊天内容；消息内更换人物入口保留。

聊天区域与桌面侧栏页签顶端对齐，不在正文上方常驻“向上滚动加载更多”提示。章节跳转后的上方片段通过滚动自动补载；补载保留当前阅读位置，只有请求进行时显示加载状态。

目录、搜索和句子链接在当前转写版本内定位时，已加载的目标直接滚动并短暂高亮，不重新加载正文或版本。未加载的目标按需取得附近窗口，等待及失败期间保留当前正文和阅读位置；目录项显示定位状态并允许改选其它章节，快速连续定位以最后一次选择为准。返回最近阅读位置不重复加载已有内容；切换人物过滤时正文必须符合新条件；切换录音、转写版本或刷新后不得复用旧数据，改字后所有已显示的同一句同步更新。URL 保留句子定位，浏览器前进后退可重新定位；不自动播放、不重建播放器。

标题、开始时间和备注点击原位编辑，每次仅展示对应字段与保存/取消操作，自动聚焦；Escape 取消，保存失败保留输入，沿用字段级并发冲突校验。标题在页面标题处编辑，不再提供整块录音信息表单。桌面正文与右栏各自滚动，滚动正文不移动右栏；向前补载在正文滚动容器中保留阅读位置。手机保持整页滚动。

## 新版本与任务反馈

无成功转写时，详情正文区分数据加载、音频预处理、转写排队/处理中、需核对和失败；处理中（包括上传服务商、提交转写、等待服务商结果和整理结果）展示旋转指示、实际阶段及任务入口，不显示“暂无转写”，不编造进度百分比。成功后自动展示激活版本；已有成功版本时重新转写不遮挡正文。未开始转写才展示空态与版本管理入口。加载或处理失败显示原因与可操作入口，不能无限显示旋转指示。

重新生成时保留正在阅读的成功版本及阅读位置，标题下显示新版本的实际阶段和任务入口；完成后提供“查看新版本”，不自动切换已有正文或激活版本。直接进入处理中版本时展示等待页，完成后自动展示该版本；等待页允许返回已有成功版本。重新打开录音也能看到较新版本的状态。状态查询失败保留已有内容并显示更新失败及重试入口；版本列表读取失败不能解释为没有转写。摘要和目录仅在当前版本成功后提供生成入口。

任务卡片优先显示录音名称、结果及可操作的错误原因；任务 ID 和内部错误代码放在默认折叠的“任务详情”中。没有失败尝试时不显示“失败 0 次”，状态与阶段相同时不重复展示。

处理任务列表刷新与轮询核对全部已展示范围，加载更多后前面任务的状态仍会更新；新任务从首页进入，失败保留已有列表。录音详情有活跃任务时约 7 秒读取状态，稳定后约 60 秒读取；后台标签暂停轮询，回到前台刷新。
