# 转写共享读取与搜索

## 范围

行为归 [转写用例](use-case/transcribe.md)，不改后端 API、持久化和权限。

## 共享数据所有者

DetailPage 为当前录音、转写版本及刷新代次创建一个 TranscriptStore，传给 useTranscriptWindow 和 useTranscriptSearch。只读窗口、目录定位和搜索不各自请求 segments。退出页面、换录音/版本或刷新时销毁旧 store，取消请求；React effect 重放允许重新使用同一对象。人物过滤只影响派生视图，不改变原始数据缓存。

Store 持有按 id 归一化的 Segment、原始分页描述、按请求键合并的在途 Promise；页面读取统一 limit=50、hide_builtin=false。分页描述包含有序 ids、previous/current/next_cursor。游标仅按服务端返回值使用，不推导、解码或拼接 offset；空首页和其 current_cursor 为同一请求的别名。anchor 先查包含目标的已缓存页，没有时请求 anchor_id；不把不连续页拼接为连续窗口。search 从首页沿 next_cursor 遍历，复用已存在页及在途请求；只有遍历到末页才报告完整搜索计数，重复游标报错。

缓存只拥有一份当前片段值；读出时通过 id 解析最新实体。成功改字调用 replace 更新实体，较旧在途响应按 revision 防止覆盖。同 revision 的后续服务端响应可更新人物连接字段。窗口 reducer 保留连续窗口和阅读位置职责，不负责网络数据所有权；它的窗口数组由同一 store 返回实体构成。

Store 请求由 store 取消控制器拥有；单个消费者离开只忽略自己的结果，不能取消另一个消费者共享的请求。销毁取消全部网络请求，并清空页、实体和在途引用；迟到响应不得回填。请求失败移除在途项，成功页仍可复用，搜索失败可重试未完成分页。store 仅在该阅读页生命周期保留，避免跨用户或跨版本泄漏。搜索全量数据的内存量与转写长度成正比；搜索结果数组只保留共享实体引用，不复制正文或保存小写正文副本，不声称固定内存上限。

## 阅读窗口与过滤

窗口请求经 store.page(cursor, anchor) 返回连续原始页，再按 showBuiltin/anchor 投影过滤；投影保留原始游标，滚动可经过全为隐藏人物的页。定位目标时仍包含内置人物。筛选切换重建窗口投影，复用原始页。原窗口的最近四个连续窗口缓存继续服务位置恢复，刷新隔离。不同页描述可重叠但不能假设缺口已加载。

## 搜索交互

输入草稿由搜索组件局部持有，约150ms无输入且IME组合结束后才发布查询；清除立即生效。详情页只在已提交查询改变时更新正文高亮。搜索缓存读取与关键字筛选分开，空查询不全量读取。缓存加载结束后按字面文本、大小写不敏感匹配；同片段多次出现只算一条，展示文本中所有命中高亮。

使用既有 Base UI Autocomplete 构成结果下拉，保留输入词，结果包含时间、说话人及首个命中附近的短上下文；结果多时限制每批显示条数并允许继续显示，避免一次挂载全部结果。上下方向选择、Enter定位，按钮与Shift+Enter保留循环跳转；Escape先关闭下拉，再次Escape清除查询。点击结果保留搜索词，不自动播放。

搜索和目录定位在当前录音路由只更新 segment 参数；保留 recording/transcription 路由身份，防止不同 key 导致详情页重建。切换真实版本才清除查询。

## 验收

单元测试使用模拟HTTP边界验证：搜索与窗口重复读取合并、anchor命中缓存、稀疏页不中断搜索遍历、失败重试、消费者取消与store销毁、旧响应不覆盖编辑、版本隔离和过滤页游标保持。

真实Go/PostgreSQL/浏览器入口验证：从录音库路由输入及下一处保留查询与audio元素；下拉高亮、鼠标/键盘定位；目录与搜索复用已读数据；滚动补载及远距离跳转保留内容；手机无溢出。执行 `vp run check`、`vp run test:transcript` 和 `concord check`。性能验证以长转写连续输入及输入期间正文不逐键渲染为依据，不把静态检查等同实测延迟。
