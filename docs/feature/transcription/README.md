# 多服务商转写

## 目标

录音通过用户选择的转写服务商生成带时间位置和说话人标签的转写版本。

## 行为

- 首批支持 Soniox 与 AssemblyAI，默认推荐 Soniox；不声明未经用户样本验证的准确率优劣。
- 用户选择录音语言，设置默认值，导入时按批次设置并允许逐条覆盖。产品提供自动检测、单语言和多语言模式；适配器报告是否可执行，不支持时提示更换模型或调整本次选项。
- 语言和模型能力由后端能力目录提供；提交前校验语言组合和音频限制；说话人标签或时间戳缺失时仍保留有效文本并明确缺失能力。
- 网页导入固定自动转写，新建转写固定开启区分说话人；设置仅保留服务商、模型和语言偏好，不显示自动转写、区分说话人或发送费用确认开关。历史已接受任务的快照不变；受理状态不明时，重新转写弹窗提示可能重复收费，点击开始转写即确认，不再要求费用开关。
- 状态可观察：排队、预处理、上传服务商、转写中、成功、失败、恢复待核对、取消。状态阶段不伪造百分比。
- 网络错误按阶段重试；不自动切换服务商，不在远端受理状态不明时重新提交付费任务。
- 重转创建独立版本，不覆盖旧文本、标签或人工校正。首个成功版本默认激活，后续版本由用户主动切换。
- 产品完整支持分段文本、时间位置、说话人、逐段改字和归属，以及 TXT、SRT、JSON 导出。
- 模型不返回说话人时允许人工创建标签；无时间戳时仍可阅读、改字与导出 TXT/JSON，禁用片段跳转和 SRT，不能伪造时间。
- 取消以本地停止使用结果为保证；服务商未支持中止时说明仍可能计费，继续处理资源清理。

每条转写支持 [复制句子引用和深链接](../sentence-links/README.md)，绑定原版本与稳定片段 ID。

## 验收

真实服务商样本验证语言选择、时间跳转与说话人区分；测试服务商边界的超时、限流和不确定提交。

[转写用例](use-case/transcribe.md) · [架构](../../architecture.md) · [转写读取设计](architecture.md)

当前转写支持[正文搜索](use-case/transcribe.md#正文搜索)，跨分页查找并定位匹配片段，不依赖 LLM。

转写偏好说明仅强调对新录音生效；服务商状态保留配置标记，管理员可直接进入服务器设置管理连接。保存失败在表单中保留原因。
