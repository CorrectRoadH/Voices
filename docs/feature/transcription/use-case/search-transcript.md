# 搜索当前转写正文

## 用户目标与起始状态

用户打开可访问的转写版本，希望找到该版本中某句话，包括尚未滚动加载的片段。

## 完整路径

1. 在正文上方输入关键词。按去除首尾空白后的字面文本、忽略大小写匹配当前校正文，不使用正则表达式或 LLM。输入即时可见，中文输入法组字期间不更新正文高亮。 {#search}
2. 等待完整搜索结果。搜索覆盖全部分页及隐藏的内置人物片段；显示匹配片段数，同一句多次出现计一个片段，所有命中文字高亮。 {#results}
3. 使用上一处、下一处、Enter 或 Shift+Enter 循环定位。也可在结果下拉中用鼠标或方向键选择后按 Enter；结果显示时间、说话人和命中附近的上下文。定位保留查询和上下文，不自动播放。 {#navigate}
4. 按 Escape 先关闭下拉，再次 Escape 或点击清除按钮移除查询与关键词高亮。结果较多时分批展示，可继续展开。 {#clear}

## 结果与异常

空查询不请求完整转写。加载中、无结果和失败分别呈现，失败可重试。同一阅读页清空后再输入可复用已读取正文；换版本、刷新或编辑文字后不得使用过期结果。离开页面取消未完成请求并释放数据，旧版本响应不能进入新视图。

验收包含跨分页命中、隐藏片段、多次命中计数、中文输入、鼠标和键盘定位，以及查询保留、文字修改、请求失败和版本隔离。
