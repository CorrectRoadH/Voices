# 校对转写片段

## 用户目标与起始状态

用户打开自己的成功转写版本，希望修正某段文字、时间或说话人归属，同时保留原文与其他片段。

## 完整路径

1. 在消息更多菜单选择“编辑文字”，进入原位编辑。轻点正文用于阅读和选字，不直接进入编辑。 {#edit}
2. 修改文字并保存。成功后该句显示校正文，播放器和阅读位置保留；与原文相同的内容不显示已校正标记。 {#save}
3. 需要调整时间或归属时选择“编辑当前片段”。可改为另一标签或明确未知，只影响当前片段；整个人物关联通过独立的“批量关联说话人”入口处理。 {#correct-assignment}
4. 重新阅读或打开旧引用，仍定位同一片段并看到最新校正。文本或时间变化使已有摘要标为过期；搜索结果随文字更新。 {#verify}

## 结果与异常

| 情形 | 可观察结果 |
| --- | --- |
| 没有修改或改后撤回 | 关闭编辑，不发送写请求、不增加修订号、不新增校正标记 |
| 只改时间或归属 | 不顺带提交未改变的文字 |
| 保存失败 | 保留草稿和具体原因，可重试 |
| 修订冲突 | 不覆盖他人的修改，保留草稿供核对 |
| 缺少时间戳 | 文字与归属仍可编辑，系统不补造时间 |

验收从消息菜单进入，检查实际保存字段、冲突保护、未修改不写入，以及同版本播放器与句子引用稳定。
