# 阅读转写并回放原句

## 用户目标与起始状态

用户已有可访问的成功转写版本，希望按发言顺序阅读、识别人物并回听某一句话。

## 完整路径

1. 从录音库打开录音，或从版本管理打开指定版本。正文按发言顺序呈现；本人靠右，其他人物靠左，内置背景声等分类默认隐藏，可切换显示。 {#open}
2. 滚动阅读，接近边界时自动补载上下文。补载保留当前内容和阅读位置；人物过滤变化后正文符合新条件。 {#read}
3. 点击气泡内的录音时间与播放图标，仅播放该句的起止范围，到结束时间暂停。时间使用录音内位置，不是发送时间。播放不请求下一页；固定播放器始终可暂停或拖动进度。 {#play-sentence}
4. 通过目录、搜索或句子链接定位目标。已有正文保留，目标短暂高亮；未加载目标先取得附近正文，快速改选时以最后一次选择为准。定位不自动播放，也不重建播放器。 {#locate}

## 结果与异常

缺少合法时间时仍能阅读和定位文字，播放入口说明不可用。加载或定位失败保留正文和位置，并允许重试。切换录音、版本或刷新后不能显示旧范围的数据；浏览器前进后退可恢复句子定位。

验收覆盖长正文分页、内置人物过滤、单句停止、快速连续定位及失败保留；核对播放器实例、播放位置与文字编辑草稿不因定位丢失。
