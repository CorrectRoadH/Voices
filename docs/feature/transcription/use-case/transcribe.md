# 选择语言并生成转写

## 用户目标与起始状态

用户已登录并导入自己的录音，希望用指定服务商、模型和语言生成一个可阅读的转写版本。服务商凭据由管理员配置；网页导入自动发起转写，本文也适用于之后主动重新转写。

## 完整路径

1. 打开录音信息的“版本与导出”，选择新建转写，检查服务商、模型和语言。模型不支持语言组合或音频超出限制时，页面说明原因，发送音频前拒绝本次请求。 {#choose-options}
2. 点击“开始转写”。系统接受任务并显示真实处理阶段和任务入口；刷新页面或离开后后台仍继续执行。受理结果不明后重新转写时，表单提示可能重复收费，点击开始即确认创建独立版本。 {#submit}
3. 等待任务完成。没有成功版本时，页面自动展示首次成功的正文；在已有成功版本上重新生成时，保留原正文和阅读位置，完成后提供“查看新版本”。 {#complete}
4. 打开新版本进行阅读；需要时在版本管理中主动激活。重新转写不覆盖旧文字、人物标签或人工校正，原版本的链接仍然有效。 {#open-version}

## 结果与异常

| 情形 | 可观察结果 |
| --- | --- |
| 成功 | 新版本可阅读、校对和导出；可靠时间位置可用于音频跳转 |
| 缺少说话人或时间戳 | 保留文字和人工编辑；允许人工创建标签；缺少时间时不能跳转音频或导出 SRT |
| 任务失败或受理结果不明 | 显示具体原因和允许的操作，按[任务恢复](recover-task.md)处理，不自动重复收费 |
| 用户取消 | 本地停止使用结果；服务商可能仍处理并收费，已知远端资源继续清理 |
| 状态读取失败 | 保留已有正文，显示更新失败与重试入口，不能解释为没有转写 |
| 恢复模式 | 禁止新建和重试，不因刷新重新提交 |

验收通过正式导入和新建入口核对请求选项、持久化任务、重启继续、版本保留及失败边界。外部服务可模拟；真实服务商准确率须用另行授权的样本验收。
