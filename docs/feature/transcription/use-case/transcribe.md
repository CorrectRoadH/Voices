# 选择语言并生成转写

Given 已导入录音，用户选择服务商、模型和语言。

When 创建转写请求并刷新页面。

Then 后台继续执行，结果保存为新版本，时间位置可驱动音频跳转。

语言组合不支持或超过服务商时长限制时，在发送音频前拒绝；上传后的任务提交超时进入待确认，不盲目收费重试。

重启后恢复已有任务；重新转写保留旧版人工修改。成功结果落库后清理远端资源。

片段复制引用、链接和编辑收纳在消息更多菜单。点击右侧播放，仅播放所选句子的起止范围，到本句结束时间暂停，不播放下一句，也不为播放请求下一页。缺少有效时间时禁用或提示；打开句子深链接仍只定位、不自动播放。

点击片段文字可原位编辑，保存只提交校正文与版本号；失败保留草稿，冲突不覆盖远端。保存不重建播放器、不重新定位已有句子锚点。

聊天正文按群聊显示，本人消息靠右、其他人物消息靠左，使用窄气泡、组内紧密间距与组尾尖角；姓名仅组首显示，头像在组首及组尾显示，播放图标与校正标记位于正文末尾。长按消息约 500ms 打开该片段菜单，支持播放本句、复制文字、复制引用、链接和编辑。右键、键盘菜单键或 Shift+F10 与更多按钮可打开同一菜单；轻点文字仍原位编辑。触点移动超过 10px、滚动、释放、取消或组件卸载均取消未触发长按；长按完成后的释放不会误触文字编辑。输入框内不接管系统选择和编辑菜单。

播放图标紧跟正文末尾，气泡内不显示时间文字；更多按钮悬浮于气泡外，不占正文宽度。原位编辑保持接近原气泡宽度，短句输入框为一行起、自适应高度，提供紧凑的保存与取消操作。右键与长按菜单在编辑当前片段下方提供批量关联说话人入口，人物选择项显示头像与姓名。

录音开始时间复用录音的 recorded_at，支持按浏览器本地时区校准到秒并保存；暂用导入时间的录音明确提示待校准。片段播放图标的悬停提示显示开始时间加 start_ms 的真实时刻，日期分隔条区分跨日，悬停保留音频偏移。校准立即更新消息时间，不改动片段偏移、音频播放位置与版本；无片段时间时禁用播放图标并提示缺少时间。

编辑保存时文字与进入编辑时完全相同（包括改后撤回）视为取消，不发送写请求、不增加版本、不新增校正标记；片段内容与原始文本相同时不显示已校正。完整编辑仅改时间或归属时，不顺带提交未改变的文字。

录音播放器固定在窗口底部，向下滚动正文时仍能播放、暂停与拖动音频进度；页面底部预留空间，目录跳转不自动播放，不重建播放器。桌面右侧提供位置固定的 AI 主题目录；移动端通过播放器上的目录按钮打开。目录行为遵循[摘要与主题目录](../../insights/README.md)：未配置 LLM 时显示配置提示，不按分钟抽取原文生成目录。

阅读页以聊天正文为主，右侧目录和录音信息保持紧凑；版本导出和人物工具默认折叠。播放器采用底部紧凑横条，手机采用两行布局。

桌面右栏用目录、摘要和录音信息三个页签分离导航、摘要阅读与管理，页签固定、内容区单层滚动；切换页签保留未保存的录音编辑草稿。当前激活状态使用标记展示，仅非激活版本提供激活操作。

正文上方不显示“转写文字”标题、新建转写、版本选择或模型状态。版本选择、状态、新建、激活与导出集中在“录音信息”的“版本与导出”中处理，默认折叠；说话人管理与内置人物片段显示控制集中在“录音信息”的“说话人与人物”中，正文直接呈现聊天内容；消息内更换人物入口保留。

聊天区域与桌面侧栏页签顶端对齐，不在正文上方常驻“向上滚动加载更多”提示。章节跳转后的上方片段通过滚动自动补载；补载保留当前阅读位置，只有请求进行时显示加载状态。

标题、开始时间和备注点击原位编辑，每次仅展示对应字段与保存/取消操作，自动聚焦；Escape 取消，保存失败保留输入，沿用字段级并发冲突校验。标题在页面标题处编辑，不再提供整块录音信息表单。桌面正文与右栏各自滚动，滚动正文不移动右栏；向前补载在正文滚动容器中保留阅读位置。手机保持整页滚动。

无成功转写时，详情正文区分数据加载、音频预处理、转写排队/处理中、需核对和失败；处理中展示旋转指示、实际阶段及任务入口，不显示“暂无转写”，不编造进度百分比。成功后自动展示激活版本；已有成功版本时重新转写不遮挡正文。未开始转写才展示空态与版本管理入口。加载或处理失败显示原因与可操作入口，不能无限显示旋转指示。

行内编辑遵循[全站交互约定](../../appearance/README.md#加载与行内编辑)，保留现有录音字段冲突重试和片段版本校验。

## 任务恢复与原因

结果待确认时，任务卡片和录音正文直接提供“重新转写”，打开新版本确认表单；用户须明确接受可能重复收费后提交，旧任务及远端操作继续保留核对。普通失败任务按后端资源状态提供“重试”，不能仅因处于上传阶段隐藏安全重试。恢复模式禁止重试与新建；恢复待核对保留核对入口。录音 ready 显示“音频已就绪”，不表示转写完成。

任务显示人可理解的错误原因、实际阶段、错误代码及已知的服务商 HTTP 状态。网络超时、请求取消、DNS、TLS、连接错误、响应读取失败、过大响应、无效 JSON、缺失有效资源 ID 与本地登记失败分别记录受控原因。不得存储或显示原始服务商错误正文、请求 URL、凭据或音频内容；原因不改变重试与隔离规则。历史任务缺少原因时明确说明未记录详细原因，不推测具体故障。

## 正文搜索

正文上方提供当前版本的搜索入口，按去除首尾空白后的字面文本匹配，忽略大小写；匹配当前校正文，不使用正则表达式或 LLM。搜索覆盖全部分页及内置人物片段，不因阅读窗口或人物隐藏而漏报。显示匹配片段数，同一句多次出现按一个片段计数，正文中的所有匹配文字高亮。

上一处、下一处及 Enter / Shift+Enter 循环定位匹配片段，保留附近上下文、不自动播放；Escape 或清除按钮移除查询和关键词高亮。空查询不请求完整转写，加载中、无结果和失败分别显示状态，失败允许重试。切换版本或离开详情取消未完成请求，旧版本结果不得进入当前视图；文字保存后搜索结果更新。
