# 选择界面语言

## 用户目标与起始状态

访客或已登录用户希望使用简体中文或 English，录音内容与转写语言独立保持原样。

## 完整路径

1. 访客在登录页选择界面语言，选择保存于当前浏览器。注册时明确选择的语言作为新账号初始偏好；登录已有账号不覆盖其偏好。 {#guest}
2. 登录后在“我的账号 → 外观设置”选择账号语言。保存成功即时生效，不重载工作台、不丢草稿、播放器和当前位置。 {#account}
3. 刷新、重新登录或更换浏览器后，读取账号保存的语言；退出或会话失效恢复访客偏好，不影响其它账号。 {#return}

## 结果与异常

保存失败保留原语言并显示可重试错误；恢复模式禁止写入账号偏好。用户内容不作为翻译键，人物名、录音和摘要原样显示。日期按界面语言格式化，时区仍使用浏览器本地时区。

语言保存成功的通知使用切换后的语言。新通知使用当前语言，已显示的历史通知可保留发生时语言；原有重试与草稿保护不变。两种语言覆盖用户和管理入口、表单与可访问名称。

验收核对账号偏好持久化和隔离、非法值、独立字段更新、访客与账号切换、保存失败及英文窄屏和深色；字典键和插值参数须一致。
