# 选择界面语言

访客可在登录页面选择简体中文或 English；选择用于当前浏览器的访客界面；注册时明确选择的语言作为新账号初始偏好，登录已有账号不覆盖其偏好。用户在我的账号的外观设置中选择账号界面语言；保存成功后即时生效，失败保持原语言并显示可重试错误。恢复模式禁止账号偏好写入。登录、账号切换和刷新读取服务端偏好，退出或会话失效恢复访客偏好。

两种语言覆盖所有已提供的用户和管理入口。用户内容不会被当作翻译键，普通人物名与录音正文保持不变。日期按界面语言格式化，时区仍为浏览器本地时区。错误 toast 和表单提示保留原有重试与草稿保护语义，新的消息使用当前语言，已显示的历史消息可保留发生时语言。

验收：隔离数据库验证账号偏好持久化、隔离、非法值拒绝及独立字段更新；真实浏览器验证访客选择、保存失败、刷新/重登/新浏览器、不同账号、页面与弹窗、英文窄屏及深色主题。字典检查要求键和插值参数一致，不遗漏用户可见静态文案。切换时不丢失未保存表单或播放状态。
