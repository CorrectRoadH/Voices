# 说话人与人物管理

## 目标

把录音内的匿名说话人标签关联到可跨录音复用的人物档案，支持查找与纠错。

## 行为

- 创建、重命名和归档人物档案；字段包括显示名、备注和可选头像。允许同名，以独立 ID 区分。
- 为转写版本中的标签指定人物档案；未关联时继续显示 Speaker 1 等标签。
- 同一人物可关联多个标签，逐段错误可改到另一标签或明确设为未知，不修改原始服务商结果。
- 人物详情列出其在当前激活版本中出现的录音，历史版本可单独查看。
- 归档保留既有引用，不允许新增关联；解除关联不删除音频与文字。

## 跨录音识别

Go 程序内置声纹模型，无需额外部署或配置；人工关联可建立人物声纹，新录音完成转写后自动关联明确匹配的人物。自动结果可纠错，不能未经确认作为后续声纹样本。推理失败不影响录音内区分说话人与人工关联。

## 分类与资料

内置背景声、音乐、系统提示音用于分类，不能编辑或归档。关联这些内置人物的片段在正文默认隐藏，可切换显示，数据与导出仍保留。普通人物同名不影响显示。详见[方案](architecture/people.md)。

人物管理页包含只读内置人物。普通人物可标记为本人，每个账号最多一个；改选时替换旧标记，允许取消。聊天阅读中本人靠右、其他人物靠左，人物配有稳定的姓名头像；本人标记保留于人物档案。

## 验收

两份录音不同标签关联同一人物后可统一筛选；逐段纠错不误改其他片段；重新转写不直接继承旧标签身份，声纹识别遵守独立的匹配与人工优先规则。
