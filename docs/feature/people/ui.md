# 人物管理与选择界面

人物选择器使用网格排列，搜索框不自动聚焦并声明关闭自动填充。保存人物关联和编辑时保留当前页面与播放器，不清空正文。

人物卡片整体链接到人物页面，卡片不再放独立编辑和查看按钮。人物页可上传、替换或移除自定义头像，默认彩色头像显示姓名首字。连续分组要求原始片段 ordinal 相邻、有效人物相同且不跨本地日期；隐藏内置片段留下的空档不能合并成连续发言。组首显示姓名，组首和组尾显示头像，中间连续片段省略重复头像。正文群聊气泡本人靠右、其他人物靠左，适配移动端，滚动接近边界自动加载，保留已加载内容和阅读位置。

人物头像处理失败时显示错误 toast，并保留表单中的失败原因。录音详情加载人物或默认转写设置失败时显示对应错误和重试入口。

人物筛选无结果显示“没有匹配的人物”并提供清除筛选，不引导用户重复创建。人物列表不为没有备注的条目展示占位说明，内置标记不重复解释。头像转换期间在头像字段显示处理状态，禁止提交尚未处理完成的头像。归档影响在归档选项附近说明。

人物相关录音列表仅在有下一页时显示加载更多页脚；没有下一页不渲染空页脚或底部分隔线。


人物行为见[关联人物](use-case/link-person.md)和[维护人物档案](use-case/manage-person.md)。群聊消息布局见[转写界面](../transcription/ui.md)。
