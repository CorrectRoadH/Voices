# 内置声纹推理

## 目标与既有约束

声纹识别是默认内置能力。启动 Voices（包括 `air .`）即可处理声纹，无 Python、独立 HTTP 服务、服务地址或引擎选择。移除 `VOICEPRINT_URL`、独立 Compose 服务及其发布镜像；保留当前人物、样本、队列、账号隔离、人工优先及匹配阈值。范围不含 STT、更改用户实际录音的标注或生产部署。

## 原生推理与打包

使用官方 `github.com/k2-fsa/sherpa-onnx-go` v1.13.8（已查明 Go 模块最新稳定版本，原 Python wheel 使用 2.0.1）。CAMPPlus ONNX 原始 SHA256 `f682b514c05d947ee3fa91cd6ec6c5c7543479a128373fa29b1faedccd21fd11`，约 27 MiB，作为仓库工件通过 `go:embed` 编入程序；附上游出处与许可，构建和运行均不下载模型。进程内 CPU 两线程，输入 s16le/16k/mono、3–10 秒，输出 192 维归一化有限向量；保留能量和削波检查。模型固定，无面向用户配置。

官方 Go 绑定需要 CGO 与动态原生库，不能承诺纯 Go 或单一静态文件。Linux amd64/arm64 正式产物采用匹配架构的 Debian Bookworm 原生编译，分发 Voices、web、lib（sherpa C API / ONNX Runtime）及许可证；程序 rpath 指向 `$ORIGIN/lib`。Docker 在应用镜像内包含库，原应用 ffmpeg 依赖保留。macOS 开发采用官方模块对应库；其它未验收平台不新增发行承诺。

`scripts/go.sh` 为本地/CI Go 统一入口，启用 CGO；Linux 链接 libstdc++。NixOS 缺少 cc 时通过 nix shell 的 gcc 提供构建环境，现有 Nix gcc wrapper 给运行时库写入可用路径；普通系统缺编译器则明确报告安装前提。Air 使用这个入口而非启动外部模型进程。CI 和测试脚本不得保留 CGO_ENABLED=0。正式构建不会依赖开发机的 Go 模块缓存：将两份 .so 复制进发布包并在干净容器内验证可运行。

## 资源所有权与生命周期

`internal/voiceprints.Engine` 由 App 持有，构造不载入模型；首次有效 Extract 惰性加载。初始化先验证嵌入 SHA，写入现有 TEMP_DIR 下随机 0700 临时目录内 0600 文件；原生加载完成或失败后移除整个临时目录，不持久化业务数据。所有提取由可取消等待的单槽串行化，包含惰性初始化；加载失败返回 inference_unavailable，下次任务可重试，不永久缓存初始化失败。

Extract 校验 PCM、等待槽、再次检查 ctx、调用同步原生推理；为每块创建 stream，所有返回路径销毁 stream；输出拷贝为 Go 数据后归一化。取消不能中断原生函数，正在运行的调用要等实际返回后才释放槽或销毁模型；返回后检查 ctx，取消结果不能发布。绝不通过后台 goroutine 超时返回后提前关闭 C 资源。模型损坏或 native crash 不能由 Go recover 保证隔离，这是进程内推理的取舍；模型为校验固定工件、音频有界。

App.Run 退出时先等待工作 goroutine 结束，再 Close Engine；Close 与 Extract 共用槽、幂等，关闭后拒绝新请求。现有任务 15 分钟总超时和数据库 16 分钟租约继续作为发布 fencing，不宣称可抢占 native 调用；正常 CPU 调用时长另实测。单进程在途任务以原子状态阻止过期时再次启动声纹 goroutine。多副本仅保证数据库有效执行槽唯一；旧调用超期时可能短暂仍在计算，但不能发布过期结果。

## 接口与迁移

保留 HTTP 状态接口中的 `configured` 字段并恒 true（兼容既有消费者，含义为内置能力可用，不代表任务成功），删除 409 voiceprints_unconfigured 路径。UI 不提供声纹面板、按钮、配置或样本管理页面；后台自动补齐任务并重试暂时失败，录音页内部观察发布并刷新人物。恢复模式禁止执行/写入，不等于未配置。底层推理仅通过 App 内部 Extract/Close 接口注入测试替身，不公开可切换 provider 配置。

由于运行库版本不同且尚无足够向量等价证据，将 profile 改为 `campplus-zh-v2:sherpa-1.13.8:s16le-16000-mono:<同SHA>`，禁止新旧混比。新增 019 迁移对所有 ready 录音的 succeeded 转写（有标签）upsert queued 并换 generation，包括旧 failed/succeeded；不更改人工/自动关联和历史标签语义。旧向量保留至对应任务成功或编辑使其失效，新 profile 查询不计入旧向量；重建在后台执行。升级前停止旧程序，不支持旧 URL 服务和新程序混跑。此迁移可排队历史录音，但不能自动覆写旧人工匿名/已关联人物。

## 验收

1. 原生 Go 模型测试：实际公开语音输入、向量维度/范数/重复结果、静音/削波/长度、取消、关闭后拒绝与临时目录回收；测试普通执行必须真的加载模型，不以 fake 作为模型验收。
2. 原有真实 PostgreSQL/ffmpeg 场景保留，fake 仅替代原生推理边界；增加 profile 升级重排队及人工关联保留断言。模型故障、取消与执行槽 fencing 继续验收。
3. 声纹浏览器、加载轮询浏览器：无声纹面板或维护按钮；人工保存恢复内部观察、自动刷新保留草稿与播放器。
4. 本地 Air 在隔离数据库/端口实际启动并触发原生声纹任务；退出回收自己创建的进程、模型临时目录。
5. vp run check；正式 Linux amd64 Docker/发行包在无 Go 模块缓存/无 Python 环境加载原生模型，arm64 原生构建由匹配架构 CI 验证。不把交叉编译成功当作运行验收。

## 调度与退出约束

领取任务优先含有效人工参考的转写（manual、普通未归档人物、ready 录音），再按更新时间和 ID 排序；参考失败不阻塞其余任务。验收让匿名任务早于人工参考排队，检查最终识别结果和人工匿名、人工关联及自动关联保留。

Go 退出先等待任务再关闭引擎，进程槽在领取前获取并在任务清理后释放。
