# 关联和纠正人物

## 用户目标与起始状态

用户有两份自己的录音，分别包含 Speaker 1 和 Speaker 2，希望将它们关联到同一个人物档案，并修正单段误认。

## 完整路径

1. 点击片段的姓名、头像或消息菜单中的“批量关联说话人”，选择未归档人物，或新建人物并关联。保存后当前版本中同一标签的全部片段更新，包括未加载的分页。 {#link}
2. 在另一份录音中将对应标签关联到同一人物，再打开人物详情，可找到两份录音中当前激活版本的发言。不同标签和明确改为未知的片段不受批量关联影响。 {#find-recordings}
3. 单段归属有误时，从“编辑当前片段”选择另一标签或未知，只修改该片段，不改变整个标签的人物关联。界面分组也不改变原始说话人分离结果。 {#correct}
4. 人工关联触发后台声纹建档。新转写不直接继承旧标签身份，而按内置声纹规则独立匹配；用户可确认、更换或解除自动关联，人工操作优先。 {#recognize}

## 结果与异常

新建人物成功但关联失败时，重试复用已创建人物，不重复创建。关联和编辑保留正文、播放器与当前位置；人物或默认转写设置加载失败显示对应原因和重试入口。

可将多个标签关联到内置背景声、音乐或系统提示音。相关片段默认隐藏，可切换显示；原文、导出和句子深链接仍保留。改回普通人物立即恢复显示，内置人物只读。

验收核对跨录音同人物查询、跨分页标签更新、单段覆盖隔离、创建后关联失败重试，以及内置分类显示与恢复。
