# 关联和纠正人物

Given 两份录音分别有 Speaker 1 与 Speaker 2。

When 用户将两者关联到同一人物档案。

Then 人物详情能查到两份录音。

单段误认可以设为未知或另一个标签；其他片段保持原归属。新转写版本没有未经确认的人物关联。

点击片段说话人姓名、头像或消息菜单的批量关联说话人入口可选择已有未归档人物或新建人物并关联。关联更新当前版本同一说话人标签的全部片段，包括未加载的分页；不同标签和明确改为未知的片段不受影响。新建成功而关联失败时重试复用已创建人物，不重复创建。

可将多个标签关联到内置人物背景声、音乐或系统提示音；其有效片段默认隐藏，可开启显示，原文、导出和句子深链接保留。改回普通人物即恢复显示。内置人物不能修改或归档，在人物管理列表标记为内置并保持只读；录音列表显示当前激活版本实际片段引用的普通人物并去重。

人物选择器使用网格排列，搜索框不自动聚焦并声明关闭自动填充。保存人物关联和编辑时保留当前页面与播放器，不清空正文。

人物卡片整体链接到人物页面，卡片不再放独立编辑和查看按钮。人物页可上传、替换或移除自定义头像，默认彩色头像显示姓名首字。连续分组要求原始片段 ordinal 相邻、有效人物相同且不跨本地日期；隐藏内置片段留下的空档不能合并成连续发言。组首显示姓名，组首和组尾显示头像，中间连续片段省略重复头像。正文群聊气泡本人靠右、其他人物靠左，适配移动端，滚动接近边界自动加载，保留已加载内容和阅读位置。

人物头像处理失败时显示错误 toast，并保留表单中的失败原因。录音详情加载人物或默认转写设置失败时显示对应错误和重试入口。

消息菜单明确区分“编辑当前片段”和“批量关联说话人”。编辑片段中的说话人归属仅修改当前片段，不修改整个标签的人物关联。界面分组与人物关联不会重新识别音频中的真实说话人。

人物筛选无结果显示“没有匹配的人物”并提供清除筛选，不引导用户重复创建。人物列表不为没有备注的条目展示占位说明，内置标记不重复解释。头像转换期间在头像字段显示处理状态，禁止提交尚未处理完成的头像。归档影响在归档选项附近说明。
