# 维护人物档案

## 用户目标与起始状态

用户已登录，希望维护跨录音复用的人物资料，设置自己的身份，并停止将某个人物用于新关联。

## 完整路径

1. 在人物列表中搜索或新建人物，点击卡片进入详情。普通人物允许同名，以独立 ID 区分；内置分类有只读标记，不能编辑或归档。 {#open}
2. 修改姓名、备注或上传头像，也可替换、移除头像。没有自定义头像时显示姓名首字的彩色头像；转换期间显示处理状态并阻止提交未处理完的头像。 {#edit}
3. 将普通人物标记为本人，聊天中其消息靠右。每账号至多一人，改选替换旧标记，也可取消；本人标记不改变访问权限或转写归属。 {#self}
4. 归档不再需要新增关联的人物。已有引用保留，新的关联与声纹匹配不使用归档人物；归档的影响在选项附近显示。 {#archive}

## 结果与异常

头像处理失败显示 toast 并保留字段原因。筛选无匹配时提供清除筛选，不引导重复创建；无备注不显示占位说明。人物相关录音只在有下一页时显示加载更多页脚。

验收覆盖同名人物、资料与头像更新、本人唯一性、取消标记、归档引用保留以及内置人物拒绝修改。
