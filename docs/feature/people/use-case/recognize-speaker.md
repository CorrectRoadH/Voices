# 标识一次，后续录音自动关联

Voices 内置声纹引擎与模型，直接启动程序或 `air .` 即可使用，无额外服务、地址或开关；用户有清晰且带时间戳的转写录音。

1. 在录音中将说话人标签关联到普通人物。系统在后台从未被单段纠错覆盖的发言建立声纹；至少需要两块清晰语音、合计六秒。样本不足不影响人工关联。{#enroll}
2. 导入另一份录音。转写完成后继续后台识别人声，仅在同账号的有效人工声纹中匹配。匹配足够明确时自动关联人物；陌生人、歧义和不合格音频保留匿名标签。{#recognize}
3. 用户可修改、解除或确认自动关联。人工修改优先；解除后的标签不再自动关联。自动结果只有经人工确认才能用于建立后续声纹。{#correct}
4. 声纹在后台自动维护，人物页与录音页不显示声纹面板、样本管理或更新/重试按钮。自动关联直接更新人物结果，用户仍可通过正常人物关联入口纠错。后台补齐遗漏任务，暂时性故障五分钟后自动重试，不重跑付费转写。{#retry}

声纹处理失败不影响导入和人工标识。内置人物不建档，归档人物不再参与匹配。删除录音、修改标签身份或修改样本片段时间/归属后，旧样本不再用于后续识别。既有自动关联不因此追溯改写，可人工纠错。

录音页内部观察后台任务，仅在排队、运行或等待自动重试时轮询，页面隐藏时暂停；完成、不可恢复失败或无任务时停止。人工保存后重新获取状态。没有合格样本的成功任务不反复计算；修改人物或片段后才按新输入重建。

不同账号的音频、声纹和候选人物互不可见。后台重启可恢复任务，过期执行结果不能覆盖新的人物标识或已删除录音。声音过短、噪声、多人重叠以及设备变化会影响识别，不保证一次标识后任何音频都能认出。

来源：[人物管理](../README.md) · [声纹架构](../voiceprints.md)。

管理员可在系统日志的运行日志查看本地声纹处理结果和安全失败原因；声纹不是外部调用，不记入 STT/AI 调用日志。
