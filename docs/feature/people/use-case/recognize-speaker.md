# 标识一次，后续录音自动关联

用户已启用自托管声纹服务，有清晰且带时间戳的转写录音。

1. 在录音中将说话人标签关联到普通人物。系统在后台从未被单段纠错覆盖的发言建立声纹；至少需要两块清晰语音、合计六秒。样本不足不影响人工关联。{#enroll}
2. 导入另一份录音。转写完成后继续后台识别人声，仅在同账号的有效人工声纹中匹配。匹配足够明确时自动关联人物；陌生人、歧义和不合格音频保留匿名标签。{#recognize}
3. 用户可修改、解除或确认自动关联。人工修改优先；解除后的标签不再自动关联。自动结果只有经人工确认才能用于建立后续声纹。{#correct}
4. 人物页显示可用声纹样本和时长，可从历史人工标识录音更新声纹。录音页显示识别状态；失败可重试声纹处理，不重跑付费转写。{#retry}

未启用服务时显示未启用，导入和人工标识照常工作。内置人物不建档，归档人物不再参与匹配。删除录音、修改标签身份或修改样本片段时间/归属后，旧样本不再用于后续识别。既有自动关联不因此追溯改写，可人工纠错。

不同账号的音频、声纹和候选人物互不可见。后台重启可恢复任务，过期执行结果不能覆盖新的人物标识或已删除录音。声音过短、噪声、多人重叠以及设备变化会影响识别，不保证一次标识后任何音频都能认出。
