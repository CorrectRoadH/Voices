# 全站界面交互

本页拥有跨功能的加载、行内编辑、操作反馈与列表交互契约。主题偏好见[界面主题](../appearance/README.md)，具体业务行为见所属 Feature；组件实现与视觉指导见 [web/DESIGN.md](../../../web/DESIGN.md)。

## 标题与错误通知

浏览器标签标题固定为 Voices。保存成功、测试通过、模型目录获取结果及操作/加载失败统一通过 Toast 提醒，不额外渲染常驻结果栏。同一错误复用通知，未解除的轮询失败不反复弹出；重试入口留在原处，失败保留草稿。字段填写说明、付费与破坏性操作后果、恢复模式和业务状态保持直接可见。用户主动取消或已废弃的请求不弹错误通知。

## 加载与行内编辑

全站初次加载以共用骨架屏和可读状态提示占位；已有内容轮询时保持可读，不反复闪回骨架。明确进行中的提交按钮显示旋转指示与 aria-busy 并禁用重复提交，普通禁用和取消按钮不表示正在提交。动画尊重减少动态效果偏好。

标题、开始时间、备注与片段文字使用一致的行内编辑交互。编辑开始时绑定当前值与保存回调，轮询不能替换草稿或更新其基准版本。单行 Enter 保存，多行 Ctrl/⌘+Enter 保存，Escape 取消；输入法组合期间不触发快捷键。保存失败保留输入，无修改时关闭且不写入；保存中禁止修改与取消，结束后焦点回到编辑入口。标题使用紧凑的单行编辑区域，多行文本可增高；不把单字段编辑扩成整页表单。

## 信息层级与操作反馈

界面以对象名称、当前状态和下一步操作为主；同一事实不同时在标题、说明、状态徽标和页脚重复显示。能直接铺开的信息优先通过分组、对齐和文字层级展示，不默认折叠。格式约束放在字段附近；会影响当前选择的失败原因、删除后果、密码修改后的退出行为和覆盖已有结果提示保持可见。无记录与筛选无匹配分别提示，后者提供清除筛选入口。

同一区域执行操作时，只在实际触发的按钮或控件旁显示忙碌反馈，其余互斥操作禁用但不显示正在执行。失败保留输入并显示具体原因。主动刷新同一列表保留已有内容；录音库、人物及任务列表切换同一账号内的筛选时保留上一组结果并明确提示正在更新，成功后整体替换，失败可重试；切换对象或账号范围立即隔离旧内容。加载更多只在分页入口显示忙碌状态。

读取请求同时支持主动取消与 30 秒超时，超时停止等待并提供重试，不自动重发写入。后台标签暂停定时读取，重新可见时刷新。文字筛选等待约 250ms 输入停顿后查询；旧响应不能覆盖新筛选，分页游标与筛选绑定。

UI 的布局、文案、状态、组件选择与验收规则见 [web/DESIGN.md](../../../web/DESIGN.md)。业务行为仍由各 Feature 与 Use Case 拥有。

日期与日期时间输入使用官方日历浮层，支持键盘填写、清除与本地时间选择；日期时间转换由具体业务入口负责，保留原有日期边界与精度语义。录音与任务列表不使用双层卡片；调用日志用单层分隔列表，完整诊断信息仍可直接读取与复制。
