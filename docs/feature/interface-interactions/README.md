# 全站交互反馈

用户在录音、人物、任务和设置页面需要知道读取或保存是否进行中、失败后怎样继续。全站使用一致的加载、行内编辑和错误反馈，保留已有内容与草稿，避免重复提交。

## 上手与行为

打开列表时先看到可读加载状态；刷新已有列表时内容保持可读。点击字段进入编辑，保存后返回阅读；失败保留输入和原因，无修改时直接关闭且不发送写请求。

主动操作失败显示通知并在对应区域保留原因，后台轮询失败只在相关区域提供重试。普通禁用不表示正在提交，用户取消或废弃请求不显示失败通知。
