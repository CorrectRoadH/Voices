# 录音摘要与主题目录

用户可在成功的转写版本上手动生成摘要及主题目录。管理员配置 OpenAI-compatible LLM 地址和模型；凭据仅在服务端使用，空密钥可用于本地模型。保存配置后重启生效，不自动生成、不静默换模型或降级重试。

生成前说明转写文本将发送给配置的服务且可能收费。结果绑定转写版本，文本或时间编辑后标为过期；结果不会覆盖转写原文。摘要与章节作为文本显示，AI 内容须核对。

桌面和移动端目录仅展示 LLM 生成的主题章节，不按分钟抽取原文。未配置 LLM 时不展示目录条目，提示管理员在服务器设置中配置 LLM 地址和模型并重启；配置后尚未生成时提示手动生成。

目录引用真实片段，可定位未加载的正文，播放器使用当前片段有效时间且不自动播放；无有效时间仅定位正文并解释原因。已过期的章节不会使用旧时间定位音频。

任务持久保存，单实例替换不丢失排队工作。运行失败或中断不自动重放；恢复数据库时 queued/running 均隔离为失败，用户再次生成前明确知晓可能重复收费。输入限 5000 个片段、200000 UTF-8 字节，超限不截断。
