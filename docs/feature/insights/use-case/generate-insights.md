# 生成摘要并跳转主题章节

## 用户路径

用户打开自己的录音，选择已成功的转写版本，在目录区域点击生成。目录区域说明发送的内容、费用可能性和重新生成覆盖旧结果；未配置时解释管理员配置步骤。

桌面侧栏和移动端目录入口在未配置 LLM 时显示配置提示，不显示时间目录或历史主题条目；配置后尚未生成时直接提供生成按钮。页面顶部不显示独立摘要卡片；桌面侧栏与移动端目录共用生成、状态和重试入口。失败显示“摘要与目录生成失败”，并在原处提供重试和灰色费用说明，不能显示为尚未生成。成功后目录页签只展示章节，摘要预览、完整阅读、模型信息和重新生成位于独立摘要页签。

提交后显示排队/生成中，禁止重复生成；刷新或切换实例仍能查看进度。完成后显示摘要、模型、生成时间和主题目录。失败只显示受控错误，不含服务商正文；再次生成是显式新请求，不自动重试。

生成失败时，服务端日志记录生成代次、受控错误码和应用定义的失败原因，以区分输出 token 上限、拒答、JSON 结构和章节校验失败；不记录转写、模型响应正文或凭据。浏览器和数据库继续使用既有受控错误码。

模型请求使用本次快照内按顺序分配的短编号（s1、s2 等），避免模型抄写数据库 UUID。输出只能引用本次提供的编号，严格校验首章、顺序和成员关系后映射回真实片段 ID；时间仍取自快照，不接受模型时间。不猜测、模糊匹配或丢弃非法章节，也不自动增加付费重试。

章节点击读取当前片段，使用 anchor 分页定位正文；有效时间定位播放器但不自动播放。无时间或零时长只定位正文并提示。修改文本或时间后标为过期，仍可按真实片段定位，重新生成刷新内容。普通用户与管理员均不可读取其他账号录音的摘要。

## 验收

真实 HTTP/PostgreSQL 与 SDK 对接外部 fake：权限、CSRF、恢复禁写、幂等、跨实例读取、并发领取、lease超时与shutdown、快照恢复queued不重放、删除级联与键回收。验证空文本/超限拒绝、非法输出锚点拒绝、SDK环境隔离、响应/输出限制、失败只调用一次。

浏览器验证真实生成、状态轮询、摘要/主题目录、未加载章节与空时间定位、过期提醒、失败与重新生成、窄屏和深色。

[设计](../../../research/transcription-insights/README.md)

目录章节采用紧凑行距，标题完整换行，时间列对齐。成功后的摘要、模型信息、重新生成与费用说明位于独立“摘要”页签；失败与重试仍直接可见。桌面侧栏固定页签、内容区保留单层滚动但隐藏常驻滚动条，支持滚轮、触摸和键盘定位章节。

摘要页签仅显示三行预览，完整摘要在独立阅读弹窗中展示，保留原文换行并支持滚动；关闭后回到原目录。

桌面右栏采用目录、摘要、录音信息三个页签；手机播放器弹出区域采用目录、摘要两个页签。切换页签不会重新生成或丢失录音编辑草稿。

LLM 配置按提交时的数据库值绑定到任务，保存后的新任务无需重启即可使用新地址、密钥和模型；已排队任务继续使用原快照，终态清除凭据。参考[站点初始化设计](../../../research/site-onboarding/README.md)。
