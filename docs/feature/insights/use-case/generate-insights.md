# 生成摘要并跳转主题章节

## 用户目标与起始状态

用户打开自己的成功转写版本，希望生成摘要并按主题回到原文。管理员已配置兼容 OpenAI 的 LLM；未配置时，管理员可从提示进入服务器设置，普通用户看到联系管理员的提示。

## 完整路径

1. 上传录音或新建转写后，成功版本在站点已配置 LLM 时自动排队生成，无需额外设置。入口说明转写文本将发送给配置服务且可能收费。历史版本或完成时未配置 LLM 的版本可在目录区域手动生成；重新生成会覆盖旧结果。只发送该版本的文字和片段锚点，不发送音频或人物档案。 {#generate}
2. 提交后看到排队或生成中，不能重复生成；刷新页面或切换实例仍可查看进度。任务使用提交时的配置，后续配置修改不会改变已接受任务。 {#wait}
3. 完成后在摘要页签阅读摘要预览、打开完整阅读弹窗，并查看模型和生成时间；目录页签显示主题章节，不按分钟抽取原文充当目录。 {#read}
4. 点击章节，定位真实片段并保留上下文。有合法时间时定位播放器但不自动播放；没有时间或零时长只定位文字并说明原因。 {#navigate}
5. 修改转写文字或时间后，旧结果标为过期。用户仍可按真实片段定位，并在摘要页签显式重新生成；定位音频必须读取片段当前时间，不能使用过期时间。 {#regenerate}

## 结果与异常

| 情形 | 可观察结果 |
| --- | --- |
| 尚无成功转写 | 不提供摘要和目录生成入口 |
| LLM 未配置 | 转写正常完成、不创建摘要任务；只显示配置提示，不展示历史主题条目或伪造时间目录 |
| 空正文或超出 5000 片段、200000 UTF-8 字节 | 自动任务显示对应失败原因，不调用 LLM，转写仍成功；手动请求拒绝生成，不静默截断 |
| 生成失败或中断 | 原处显示受控原因和重试入口，不显示为尚未生成；不自动重放，再生成可能再次收费 |
| 普通应用重启 | 已排队任务继续，运行中断只失败，不自动再收费 |
| 数据库快照恢复 | 排队和运行任务均隔离为失败；恢复前尚未完成的上传和转写在恢复后完成时也不自动生成，须手动生成或显式新建版本；成功结果保留 |
| 他人录音或删除中录音 | 不可读取或生成，管理员无越权例外 |

验收以真实 HTTP、PostgreSQL 和浏览器覆盖生成、状态、章节定位、过期提醒与重新生成；外部模型边界用模拟服务核对请求次数和脱敏。并发、取消、删除与配置快照清理按生命周期契约验证。
