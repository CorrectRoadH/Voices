# 复制句子引用并返回原位置

1. 用户在历史转写版本的消息菜单选择“复制引用”，得到 `[张三: 明天上午讨论方案](https://voices.example/q/Ab3kP9x2Lm7Q)`，也可仅复制短 URL。正文与人物名按标准 Markdown 转义，不附来源行、录音名称或时间。 {#copy}
2. 选择“多选”时自动选中当前段，气泡外左侧显示对齐的圆形勾选框，整行高亮已选消息；点击正文、勾选框或行内空白增减，最多100段。Shift 点击将上次选择到当前消息之间已加载且可见的消息加入选择，超过上限时整次拒绝。完整加载的同人物连续发言组提供“选择这组发言”。选择模式隐藏单条操作并禁止正文编辑及人物修改，跨分页保留已选段；切换录音、版本、内置人物筛选或搜索条件清空选择。Escape 或取消退出多选。 {#select}
3. 固定操作栏显示已选数量、复制文字、复制引用和取消；桌面位于正文上方，手机固定于播放器上方。复制两段及以上时按原文顺序输出一个 `> [!quote]+ [查看原录音](绝对短链接)` 引用块，链接定位首段；每段保留各自姓名和正文，段间使用 `>` 空行，跳过原文则在块内插入“〔中间有省略〕”。标题不放姓名；单段沿用原链接格式。既有带 `?at=2` 等组内位置的链接仍有效。复制文字保留姓名、段落与省略标记，不含链接。自动复制成功提示数量并退出选择，无预览确认。请求失败保留选择并提示；剪贴板失败弹出全选原文的手动复制窗口，关闭窗口仍保留选择，可重试，不能把关闭视作复制成功。复制等待期间离开页面、切换范围或取消，不得在新页面复制或弹出旧内容。 {#copy-selection}
4. 从 Obsidian 点击短链接，未登录者先登录，再进入原转写版本和所点片段，必要时加载分页。原激活版本不因此改变。显示引用段数及前后跳转，当前窗口中的引用成员有淡色标记，完整上下文仍可阅读。有时间信息时只定位音频，不自动播放；无时间信息仍定位正文。 {#open}
5. 手工校正文与修改人物不改变链接或成员；复制文本保留当时内容，页面展示最新校正内容。重新转写不会重定向旧引用。删除录音、无权限、未知短码或非法组内位置时明确不可用。原三个 UUID 的长链接仍可定位。 {#stability}

定位以正文实际滚动容器为准，目标消息居于可视阅读区域中部（首尾边界允许受剩余内容限制）；手机按播放器上方的可视窗口定位。等待正文与字体布局就绪后定位，分页补载保留阅读位置，不与初次定位竞争滚动。目标以整行淡色背景短暂强调后淡出，不保留气泡描边；重复定位同一句重新强调。减少动态效果偏好下仅短暂显示静态背景。搜索和目录跳转复用相同定位反馈。
