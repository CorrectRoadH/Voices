# 复制句子引用并返回原位置

1. 用户在历史转写版本的消息菜单选择“复制引用”，得到 `[张三: 明天上午讨论方案](https://voices.example/q/Ab3kP9x2Lm7Q)`，也可仅复制短 URL。正文与人物名按标准 Markdown 转义，不附来源行、录音名称或时间。 {#copy}
2. 选择“多选”时自动选中当前段，点击正文或复选框增减，最多100段；完整加载的同人物连续发言组提供“选择这组发言”。选择模式禁止误触正文编辑及人物修改，跨分页保留已选段；切换录音、版本、内置人物筛选或搜索条件清空选择。 {#select}
3. 复制多段时按原文顺序输出，每段为独立 Markdown 链接，段间空行；跳过原文则插入“〔中间有省略〕”。后续段的 URL 带 `?at=2` 等组内位置。请求失败保留选择并提示，剪贴板失败弹出手动复制。复制等待期间离开页面、切换范围或取消，不得在新页面复制或弹出旧内容。 {#copy-selection}
4. 从 Obsidian 点击短链接，未登录者先登录，再进入原转写版本和所点片段，必要时加载分页。原激活版本不因此改变。显示引用段数及前后跳转，当前窗口中的引用成员有淡色标记，完整上下文仍可阅读。有时间信息时只定位音频，不自动播放；无时间信息仍定位正文。 {#open}
5. 手工校正文与修改人物不改变链接或成员；复制文本保留当时内容，页面展示最新校正内容。重新转写不会重定向旧引用。删除录音、无权限、未知短码或非法组内位置时明确不可用。原三个 UUID 的长链接仍可定位。 {#stability}

定位以正文实际滚动容器为准，目标消息居于可视阅读区域中部（首尾边界允许受剩余内容限制）；手机按播放器上方的可视窗口定位。等待正文与字体布局就绪后定位，分页补载保留阅读位置，不与初次定位竞争滚动。目标以整行淡色背景短暂强调后淡出，不保留气泡描边；重复定位同一句重新强调。减少动态效果偏好下仅短暂显示静态背景。搜索和目录跳转复用相同定位反馈。
