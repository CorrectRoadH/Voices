# 逐句转写深链接

## 目标

用户能引用录音中的一句话，并从引用准确返回该转写版本中的位置。

## 行为

- 每条转写句子提供复制引用，格式为 `[说话人: 句子内容](绝对链接)`；另可单独复制 URL。
- 引用文字使用当前人物显示名或说话人标签及校正文；未知说话人有明确占位。正确转义 Markdown 特殊字符。
- 链接包含录音、转写版本与片段的稳定 ID，不包含音频凭据、人物名或正文。
- 打开链接后选择对应版本、加载片段所在分页、滚动并高亮；有时间戳时定位音频，不自动播放。
- 编辑文字或人物不改变链接；重新转写不替换旧链接指向的版本。复制出的文字为复制时快照，页面显示当前校正内容。
- 没有时间戳仍可定位文字；目标删除或归属不匹配明确不可用，不猜测另一个目标。
- 链接仍要求登录；登录后回到原句，不新增匿名分享权限。剪贴板失败时提供手动复制。

## 验收

校正文字、修改人物、切换激活版本并重新转写后，旧链接仍定位原版本和片段。
分页外片段、无时间戳、登录跳转、删除目标和含方括号的文本均有明确行为。
