# 逐句转写深链接

## 目标

用户能在 Obsidian 等 Markdown 笔记中引用录音的一段或多段话，并点击引用准确返回原转写版本。

## 行为

- 单段和多段引用均使用本站短链接，逐段输出 `[说话人: 正文](绝对短链接)`，不附来源行、录音标题或时间。另可单独复制 URL。
- 多选限定同一转写版本的 1–100 个片段，按原文顺序输出，保留段落；不连续片段之间明确标出省略。不同人物逐段标明姓名。
- 消息菜单提供多选，当前段自动选中；选择模式下点击正文或复选框切换选择，禁止误触编辑。完整加载的连续发言组可一次选择，窗口截断的组不提供全部选择。跨分页保留选择，取消或切换录音、版本、内置人物筛选、搜索条件时清空。
- 引用文字使用当前人物显示名或说话人标签及校正文；未知说话人有明确占位。正确转义 Markdown 特殊字符，粘贴后正文可点击。
- 短链接不含人物名或正文，固定绑定原版本与所选片段；原有长链接继续有效。
- 点击某段引用后加载该段所在分页、滚动并高亮；同组其他引用段可前后跳转，保留完整上下文。有时间戳时定位音频，不自动播放。
- 编辑文字或人物不改变引用成员；重新转写不替换旧引用版本。复制出的文字为复制时快照，页面显示当前校正内容。
- 没有时间戳仍可定位文字；目标删除、位置越界或归属不匹配明确不可用，不猜测另一个目标。
- 链接仍要求登录及原录音访问权限；登录后回到原引用，不新增匿名分享权限。剪贴板失败时提供手动复制；请求失败保留选择，可重试。恢复核对模式不创建短引用。

## 验收

校正文字、修改人物、切换激活版本并重新转写后，旧链接仍定位原版本和片段。多段顺序、省略、跨页定位、登录返回、账号隔离、删除失效与 Markdown 特殊字符均有明确行为。
