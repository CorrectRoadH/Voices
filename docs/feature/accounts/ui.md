# 服务器设置界面

服务器设置按单栏纵向排列站点、STT 和 LLM 配置，各卡片左侧对齐，不将 STT 放在独立右栏。常驻说明只保留输入格式、用途及影响操作的必要信息；密钥配置状态不重复显示，当前实例与保存值不一致时才显示生效差异。自动保存由状态行反馈，连接测试的费用提示使用简短文案。

自动保存串行执行且只提交变化字段；保存期间可以继续输入，旧响应不能覆盖新输入或清除新输入的密钥。首次打开和没有变化时不发起保存。输入法组字及字段格式不合法时暂不保存。界面显示未保存、保存中、已保存或失败状态；失败保留输入，停止自动重试，允许显式重试。修订冲突不会覆盖其它页面的修改，提示刷新页面后重新编辑。

自动保存与获取模型失败时显示错误 toast，并保留原有错误说明及待保存输入；自动保存成功通过页面状态提示，不逐次弹窗。

统一登录在独立卡片配置名称、Issuer URL、Client ID 和 Client Secret，使用独立修订号自动保存并立即生效；回调地址由当前生效的站点 Base URL 推导。保存密钥不回显，修改目标身份平台或客户端时须明确更换或清除旧密钥。配置和账号行为见[统一身份登录](use-case/oidc-login.md)。


模型选择直接使用模型名称输入框的下拉列表，同时保留手填模型 ID；不增加独立搜索框或选择字段。获取失败或空列表保留当前模型，连接参数变化后废弃旧列表和在途结果。

编辑停止 800 毫秒后自动保存，离开表单立即提交待保存变更；不提供手动保存或重新加载按钮。

通用加载、草稿和错误反馈遵循[全站交互](../interface-interactions/ui.md)，配置行为见[管理服务器配置](use-case/manage-server.md)。
