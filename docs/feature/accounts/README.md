# 独立账号与系统管理

## 目标

每个账号拥有独立的录音、人物、转写、音频和偏好。首个成功注册的账号成为系统管理员，后续账号为普通用户。

## 行为

使用邮箱、用户名和密码注册，用户名或邮箱加密码登录。会话保存于 PostgreSQL，跨实例有效。用户可以修改显示名称和密码。管理员管理账号启停、角色和注册开关，不能通过业务接口访问他人内容。最后一个有效管理员不能被停用或降级。

初始允许注册。服务商密钥由数据库管理，首次从环境导入，已启用的账号共用服务商额度。管理员可关闭后续注册。密码不再来自环境变量中的共享管理员密码。

界面将个人录音、人物、处理任务和转写偏好放在主导航；管理员独享的账号管理和服务器设置放在“服务器管理”分组。个人资料与密码由侧栏底部账号入口进入，显示当前用户名与邮箱。

## 验收

真实数据库并发注册恰好产生一个首位管理员。两个账号在所有业务接口与后台任务中相互隔离。改密码和停用撤销会话。

[设计](../../research/account-isolation/README.md) · [注册](use-case/register.md) · [隔离](use-case/isolate-data.md) · [权限管理](use-case/manage-access.md)

邮箱仅作为登录标识，不把注册视为邮箱所有权验证，本期不发送验证邮件。

登录允许用户名或邮箱，用户名为唯一登录别名，大小写不敏感，允许 2–32 个字母、数字或下划线（含中文）；不能含 @，因此不会与邮箱产生歧义。注册页面填写用户名并作为初始显示名称，个人资料可分别修改用户名与显示名称。既有唯一且合法的显示名称自动成为用户名；其它旧账号继续邮箱登录，可在个人资料设置用户名。不改变 user ID、密码、角色、会话或数据归属；两种登录方式共享账号失败限流。

[服务器配置](use-case/manage-server.md)管理站点、STT 与 LLM，数据库优先于 .env。
