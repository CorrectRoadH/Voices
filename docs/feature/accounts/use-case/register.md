# 注册账号与首位管理员

## 用户目标与起始状态

访客希望创建独立账号。站点允许注册且不在恢复模式；如果首位管理员已创建，须等待站点初始化完成。

## 完整路径

1. 填写邮箱、用户名和密码并提交。邮箱和用户名规范化后分别唯一，显示名称可重复；网页使用用户名作为初始显示名称。邮箱用于登录，不代表已验证邮箱所有权，也不发送验证邮件。 {#register}
2. 首次成功注册者成为管理员并进入独立站点初始化；后续账号为普通用户，直接进入个人工作台。客户端不能选择角色，注册失败不消耗首位资格。 {#enter}
3. 退出后用用户名或邮箱加密码登录，仍进入同一账号并读取该账号保存的界面语言。错误凭据显示统一错误。 {#login}

## 结果与异常

跨实例并发注册只产生一个首位管理员。重复邮箱或用户名、关闭注册、恢复模式以及初始化未完成均拒绝相应注册，不产生孤立账号或会话。

注册页明确选择的语言作为新账号初始偏好；API 省略 `ui_language` 时为 `zh-CN`，仅接受 `zh-CN` 与 `en`，null 拒绝。访客选择不覆盖既有账号的语言。

登录、注册或退出失败时显示错误 toast，并保留对应字段或页面原因和输入。验收覆盖并发首位资格、失败回滚、重复标识、注册分流与两种登录方式。
