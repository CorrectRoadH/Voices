# 注册账号与首位管理员

## 行为

访客用邮箱、用户名和密码注册。邮箱去除首尾空白并转为小写后唯一，用户名标准化后唯一，作为可选登录别名；显示名称可以重复。密码保存为 bcrypt 哈希。首次成功提交的注册获得 admin 角色，其他用户获得 user 角色，客户端不能指定角色。

首次资格与注册事务原子提交，失败不消费资格，跨实例并发只产生一个首位管理员。初始化标记持久保留。注册关闭或恢复模式下拒绝注册。

## 验收

并发不同用户名注册只产生一个 admin。重复邮箱不产生账号或会话。成功注册可立即使用个人工作台。后续登录可用用户名或邮箱加密码，错误凭据返回统一错误。

邮箱仅作为登录标识，不把注册视为邮箱所有权验证，本期不发送验证邮件。
