# 修改个人资料与密码

## 用户目标与起始状态

用户已登录，希望维护自己的用户名、显示名称和登录凭据。

## 完整路径

1. 从侧栏底部账号入口进入“我的账号”，查看当前用户名与邮箱；分别修改用户名和显示名称。用户名为唯一登录别名，显示名称可重复。 {#profile}
2. 已有本地密码时，填写旧密码和新密码；通过统一登录创建且无本地密码时，可直接设置首个密码，无需填写不存在的旧密码。 {#password}
3. 密码保存成功后，所有设备上的本站会话退出；使用新密码重新登录。解绑统一登录前必须已设置本地密码，解绑也会退出所有会话。 {#relogin}

## 结果与异常

用户名冲突或保存失败保留输入并提示，不改变身份、角色或数据归属。界面语言和主题在外观设置中管理，各自遵循独立的偏好规则。

验收核对唯一用户名、重复显示名称、旧密码校验、无密码账号设置首个密码及全部会话撤销。
