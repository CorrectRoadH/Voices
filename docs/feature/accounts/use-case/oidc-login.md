# 统一身份登录与账号绑定

## 目标与起始状态

用户通过站点管理员配置的标准 OIDC 身份平台登录 Voices。站点初始化已完成；本地密码登录始终保留用于恢复。仅支持 OAuth2 而不提供 OIDC 身份声明的平台不属于通用接入范围。

## 完整路径

1. 管理员在服务器设置填写统一登录名称、Issuer URL、Client ID 和 Client Secret，将页面提供的回调地址登记到身份平台并启用。配置自动保存，成功后供新登录立即使用；密钥不回显，留空保留，显式清除才删除。配置冲突保留草稿并提示刷新，普通用户不能查看或修改配置。 {#configure}
2. 访客在登录页选择“使用 {名称} 登录”，在身份平台认证后返回本站。取消或验证失败显示可重试错误，不建立本站会话。过期、重复或属于另一个浏览器的返回不能登录。 {#login}
3. 已绑定身份进入原账号并保留其权限和数据。新身份仅在开放注册时使用已验证邮箱创建普通账号；邮箱已被使用时提示先登录原账号并主动绑定，绝不自动合并。停用账号不能登录；关闭注册不阻断已绑定用户。 {#provision}
4. 已登录用户在个人账号页主动绑定统一身份，成功后可使用该身份登录。已绑定给其它用户的身份不能重新绑定。绑定不会改变本地邮箱、角色或已有数据。 {#link}
5. 无本地密码的用户可在账号页设置首个密码；已有密码时修改必须验证旧密码。设置或修改后退出所有会话。只有已设置本地密码才允许解绑统一登录，解绑后退出所有会话。 {#recover}

## 边界与验收

站点配置变化使未完成的登录失效，用户需重新开始。首位管理员通过本地注册建立，第三方登录不能取得首位管理员资格。恢复模式禁止新建账号和绑定变更，但允许已有绑定用户登录。退出本站撤销本站会话，不声明退出身份平台。身份平台故障时本地密码入口仍可使用。

验收覆盖管理员配置、真实浏览器往返、首次建号、已有身份登录、账号绑定、同邮箱冲突、停用与关闭注册、密码设置、解绑、错误回调和跨实例处理。具体实现与安全约束见[设计](../oidc-design.md)。
