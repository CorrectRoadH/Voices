# 初始化站点

首位管理员创建账号后进入独立站点初始化页；账号创建与站点初始化分别持久化，中断后登录可继续。初始化完成前暂停后续注册，普通用户不能配置站点；旧站点升级保留已完成状态。恢复模式仅查看，不强制初始化。

管理员填写 LLM 地址、密钥和模型，可获取模型列表并显式测试。测试使用已保存修订的一段固定示例，执行一次真实 Chat Completions JSON 生成校验；不发送用户录音，不自动重试，界面提示可能产生费用。获取列表不代表测试通过。测试失败保留配置，错误不泄露凭据；配置变化使测试状态失效，在途旧结果不能确认新修订。

完成初始化要求当前修订测试通过，或管理员明确选择暂不启用 LLM（地址、模型、密钥均为空）。站点完成状态不因日后修改配置而复位。LLM 配置保存后立即供新任务使用，已接受任务保留提交时配置并在终态清除秘密快照。站点地址和 STT 可在初始化页或服务器设置管理，修改后需重启。

部署仅要求数据库连接及适用的基础运行参数，.env 文件可选；无需预先填写 LLM 配置。外部部署须提供正确 PUBLIC_BASE_URL，不能信任请求 Host 自动扩大可信来源。

## 验收

真实 PostgreSQL 与浏览器覆盖首次创建管理员、刷新继续初始化、配置并测试、测试失败和修改失效、完成进入工作台、普通注册分流和显式跳过。验证权限、CSRF、恢复模式、并发首位资格及配置修订冲突。外部模型使用 fake，业务 API 不模拟；验证任务快照、跨实例生效及秘密清理。
