# 初始化站点

## 用户目标与起始状态

首位管理员已创建账号，希望完成站点配置。账号创建与站点完成是两个状态；刷新或退出不会丢失已保存配置。旧站点升级保留已完成状态。

## 完整路径

1. 登录后进入独立初始化页；中断后可再次进入继续。初始化期间暂停后续注册，普通用户不能配置站点。 {#resume}
2. 填写 LLM 地址、密钥和模型，可获取模型列表；等待自动保存。站点地址和 STT 也可在此配置，保存后需重启才生效。 {#configure}
3. 显式测试已保存修订。测试用固定示例执行一次真实生成协议校验，不发送录音，可能产生费用，不自动重试；模型列表不代表测试通过。 {#test}
4. 当前修订测试通过后完成初始化；也可清空 LLM 地址、模型和密钥，明确选择暂不启用。完成后进入工作台，不因以后修改配置重新进入初始化。 {#complete}

## 结果与异常

测试失败保留配置并显示脱敏错误；任何配置修改使旧通过状态失效，在途结果不能确认新修订。LLM 保存立即供新任务使用，已接受任务保持原配置。

恢复模式只允许查看，不强制初始化。部署只要求数据库连接及适用的基础参数，`.env` 文件可选；外部访问须配置正确的 `PUBLIC_BASE_URL`，不能从请求 Host 自动扩大可信来源。

验收通过真实数据库与浏览器核对中断继续、测试失败及失效、完成与显式跳过、并发修订保护和普通注册分流；仅外部模型边界使用模拟服务。
