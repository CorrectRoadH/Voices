# 管理账号与会话权限

## 行为

用户修改密码需提供旧密码，成功后撤销全部会话。管理员可分页查看账号摘要并修改角色、启停状态和注册开关。普通用户不可调用管理接口，管理员也不能读取他人业务内容。

启停、角色和注册开关修改与审计同事务。并发操作不能停用或降级最后一个 active admin。停用立即阻止后续鉴权，已接收的后台任务继续完成与清理。恢复模式禁止账号管理写入。

## 验收

改密码与停用撤销既有会话，重新启用允许新登录。角色变化影响下一次管理请求。普通用户被拒绝，最后管理员保护在并发修改下仍成立。

角色、启停和注册开关修改均显示操作中的反馈；仅当前操作显示 loading，同页其它写操作暂时禁用。失败保留原因，注册开关保存失败恢复原值。
