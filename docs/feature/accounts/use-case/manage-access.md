# 管理账号与会话权限

## 用户目标与起始状态

管理员已登录，希望调整账号角色、启停状态或注册开关，同时保留至少一个有效管理员。

## 完整路径

1. 进入账号管理，分页查看账号摘要，可按邮箱、用户名或显示名称搜索并按角色、状态筛选。 {#find}
2. 修改目标账号角色或启停状态，或切换注册开关。只在当前动作显示忙碌状态，其它互斥操作暂时禁用。 {#change}
3. 成功后检查新状态及管理审计。停用使旧会话失效，重新启用允许新登录；角色变化影响下一次管理请求。 {#verify}

## 结果与异常

普通用户不能调用管理接口；管理员不能因此读取他人的业务内容。并发修改也不能停用或降级最后一个有效管理员。恢复模式禁止管理写入。

修改失败保留原因，注册开关保存失败恢复原值。停用不撤回已发送的请求，已接受的 STT 任务继续完成与清理；排队摘要的停用处理见摘要生命周期。

验收核对权限、并发最后管理员保护、会话撤销、角色即时生效以及修改与审计一致。个人资料和密码使用独立账号入口。
