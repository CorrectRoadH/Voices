# 账号之间的数据隔离

## 行为

可信账号身份来自服务端会话，不能由请求指定归属。录音、人物、音频、转写、片段、任务和个人偏好按账号隔离，系统管理员同样遵守。

他人资源与不存在资源统一返回 404。列表、过滤、分页、下载 Range、导出、句子链接和任务操作均不能泄露他人数据。关联他人人物或标签不能成功。相同音频或相同幂等键在不同账号中互不影响。

后台任务沿用所属录音的账号，复合外键拒绝跨账号关联。GC 与远端清理继续遵守既有租约和不确定请求约束。

## 验收

两个真实账号交叉调用全部业务端点。正常账号流程仍可完成，越权读写失败且原数据不变。同音频和同幂等键在两账号分别成功，偏好互不覆盖。
