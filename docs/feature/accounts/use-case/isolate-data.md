# 账号之间的数据隔离

## 用户目标与起始状态

两个已登录账号分别拥有自己的录音、人物和转写，希望各自工作且不泄露内容。管理员同样受业务数据隔离约束。

## 完整路径

1. 账号 A 导入录音、关联人物并保存转写偏好，在列表、搜索、播放、导出和句子链接中读取自己的结果。 {#own-data}
2. 账号 B 打开 A 的资源链接或直接调用读写接口，收到与资源不存在相同的 404；关联 A 的人物或标签也不能成功。 {#other-account}
3. 账号 B 导入相同音频或使用相同幂等键，仍创建自己独立的录音；偏好和后台处理结果不覆盖 A。 {#independent}

## 结果与异常

分页、过滤、Range 下载、导出、句子链接和任务操作均不得泄露他人数据。客户端不能指定归属；管理员管理权限不授予业务内容读取权。

验收以两个真实账号交叉调用业务端点，验证正常路径可完成、越权读写失败且原数据不变，以及同音频、同幂等键和偏好分别独立。
