# 管理服务器配置

## 行为

服务器设置按单栏纵向排列站点、STT 和 LLM 配置，各卡片左侧对齐，不将 STT 放在独立右栏。

管理员从服务器管理进入服务器设置，管理站点 Base URL、额外可信来源、Soniox / AssemblyAI STT 密钥，以及兼容 OpenAI 接口的 LLM 地址、模型和密钥。LLM 用于用户手动生成[录音摘要与主题目录](../../insights/README.md)，地址与模型必填，空密钥可用于本地服务。

数据库配置优先于 .env。首启导入环境中的业务配置，之后数据库中的空值也具有优先权。环境仍负责数据库连接、监听、目录、恢复模式和资源限制。编辑停止 800 毫秒后自动保存，离开表单时立即提交待保存变更，不提供手动保存或重新加载按钮。保存写入数据库，所有应用副本重启后生效，界面区分已保存与当前实例生效值。

自动保存串行执行且只提交变化字段；保存期间可以继续输入，旧响应不能覆盖新输入或清除新输入的密钥。首次打开和没有变化时不发起保存。输入法组字及字段格式不合法时暂不保存。界面显示未保存、保存中、已保存或失败状态；失败保留输入，停止自动重试，允许显式重试。修订冲突不会覆盖其它页面的修改，提示刷新页面后重新编辑。

密钥输入留空保留，明确清除时保存空值。读取接口仅显示是否配置，响应、日志和审计不包含密钥。数据库及备份须按包含凭据保护。STT 换到其它服务商账号前须完成旧账号的任务和远端清理。

普通用户不可读取或修改服务器配置；写入校验 CSRF、来源、恢复模式及修订号。并发旧修订不覆盖新值。修改与不含秘密的字段名审计同事务提交。

管理员可点击“获取 LLM 模型”，使用当前表单地址与密钥获取模型列表，直接在模型名称输入框的下拉列表选取模型，也可继续手填模型 ID；不提供独立搜索框和模型选择字段。该操作不保存配置、不生成内容，列表不代表模型已通过 Chat Completions / JSON 输出验证。获取失败或空列表有明确提示，不覆盖当前模型。

获取模型沿用管理员、CSRF、来源、恢复模式及修订号检查。省略密钥只允许在地址与已保存地址一致时使用已保存密钥；更换地址须输入新密钥或明确使用空密钥，不能隐式向新地址发送旧密钥。服务端禁止跟随重定向，限制时间、响应大小与模型数量，不返回服务商原始错误。连接参数变化后废弃旧列表与在途结果。

[模型发现接口设计](../../../research/openai-stt-model-discovery/README.md)

## 验收

浏览器验证停顿自动保存、离开表单提交、持续输入和慢响应时不丢草稿、不重复保存、密钥清除、失败保留及修订冲突保护。

验证首启导入、并发启动、数据库优先、空值不回退环境、STT 实际凭据、权限隔离、非法值拒绝、修订冲突和密钥不回显。管理员可保存配置并看到待重启提示；普通用户无入口且 API 拒绝访问。

[设计](../../../research/server-settings/README.md)

验证模型列表的权限、密钥与目标绑定、修订冲突、网络错误、格式及大小限制；浏览器验证获取、输入框内选择、手填，以及连接变化时废弃旧响应。

自动保存与获取模型失败时显示错误 toast，并保留原有错误说明及待保存输入；自动保存成功通过页面状态提示，不逐次弹窗。
