# 管理服务器配置

## 用户目标与起始状态

管理员已登录，希望配置站点地址、可信来源、STT 和 LLM 服务，供账号使用实例能力。数据库、监听地址、临时目录、恢复模式和资源限制由部署环境管理。

## 完整路径

1. 从服务器管理进入服务器设置，查看站点、STT 和 LLM 卡片。LLM 用于转写成功后自动生成录音摘要与目录，并支持手动生成；地址与模型必填，本地无认证服务可以使用空密钥。 {#open}
2. 修改需要的字段，停顿或离开字段后观察自动保存状态。密钥输入留空保留，明确清除才保存空值；保存失败保留输入并允许显式重试。 {#edit}
3. 点击“获取 LLM 模型”，按当前表单地址与密钥读取列表，在模型输入框内选取或手填 ID。获取本身不保存配置、不生成内容；失败或空列表不覆盖原模型。 {#discover-models}
4. 等待自动保存完成后显式测试当前修订。测试使用固定示例验证真实生成协议，可能收费且不自动重试；配置变化使测试结果失效，旧结果不能确认新修订。 {#test}
5. 保存后的 LLM 配置立即供各实例的新任务使用；已接受任务保留原配置。站点地址、可信来源和 STT 配置需重启全部应用副本，页面显示当前实例与保存值的差异。 {#apply}

## 结果与异常

数据库配置优先于 `.env`，已保存的空值也不回退环境。普通用户不可读写配置，恢复模式禁止写入；旧修订不覆盖新值。更换 LLM 地址且已有密钥时须明确更换或清除密钥；切换 STT 服务商账号前须完成旧账号任务和远端清理。

读取接口只显示密钥是否配置，日志与审计不包含秘密。数据库和备份按包含凭据保护。统一登录由独立卡片配置并立即生效，使用独立修订号；具体路径见统一身份登录。

验收核对自动保存、持续输入和慢响应不丢草稿、失败显式重试、修订冲突、密钥保护、模型发现与测试的区别，以及 LLM 跨实例立即生效和已接受任务使用旧配置。

## OpenAI STT

OpenAI STT 卡片提供独立 Base URL/API Key，空地址使用 https://api.openai.com/v1；空密钥禁用，不借用 LLM 密钥。更改地址时须同时重新输入或明确清除旧密钥。保存不调用服务商，重启后在转写选项显示 gpt-4o-transcribe-diarize，支持说话人与时间戳，最大文件 25 MB。
