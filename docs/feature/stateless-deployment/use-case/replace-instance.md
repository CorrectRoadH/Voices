# 替换实例不丢失已接受数据

## 用户目标与起始状态

部署者有 A、B 两个使用相同部署配置并共享 PostgreSQL 的实例。用户已登录，希望替换应用实例后继续访问数据。

## 完整路径

1. 通过 A 导入录音并收到成功响应。 {#accept}
2. 销毁 A 及其临时磁盘，将请求交给 B。B 继续识别会话，读取原始音频、播放副本及转写，并允许编辑人物关联。 {#replace}
3. 等待已领取任务的租约到期，由 B 接管。尚未开始远端操作的任务可继续；已有远端 ID 的任务只查询原任务，不确定操作不重新提交收费请求。 {#resume}

## 结果与异常

上传成功响应前销毁 A 可能使上传失败；重传不产生重复录音，过期未发布块被回收。普通实例替换不等于数据库快照恢复；快照恢复必须按独立恢复步骤隔离旧任务。

验收使用两个真实应用实例和 PostgreSQL，核对会话、音频摘要、导入选项、版本与人物保留，并检查旧租约不能发布、已知远端创建操作不重复执行。
