# 切换界面主题

用户登录后通过侧栏账号入口进入“我的账号”，在“外观设置”的“界面主题”选择跟随系统、浅色或深色，无需提交表单，整页即时采用所选外观。登录页与侧栏不显示主题选择器，仍应用当前浏览器主题。

- 没有有效偏好时跟随系统；运行期间系统变化也生效。
- 手动选择不受系统变化影响，刷新、退出登录后仍保留；切回跟随系统恢复实时跟随。
- 同源其他标签页的选择及清除偏好同步生效。
- 存储不可用时界面仍可使用与切换，不使登录或工作台崩溃。
- 首屏采用正确主题，原生控件的 color-scheme 和浏览器 theme-color 与实际主题一致。
- 桌面和 375px 窄屏都能操作，转写气泡、弹窗和表单内容可读。
