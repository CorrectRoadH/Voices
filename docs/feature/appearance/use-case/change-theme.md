# 切换界面主题

## 用户目标与起始状态

用户已登录，希望在当前浏览器选择舒适的配色。没有有效偏好时跟随系统。

## 完整路径

1. 从侧栏账号入口进入“我的账号 → 外观设置”，找到界面主题。 {#open}
2. 选择浅色或深色，无需提交，整页立即变化；手动选择不受系统配色变化影响。切回跟随系统后恢复实时跟随。 {#choose}
3. 刷新、退出登录或打开同源标签页，仍看到保存的主题；其它标签页选择或清除偏好后同步生效。登录页和侧栏不额外显示选择器。 {#persist}

## 结果与异常

浏览器存储不可用时仍能切换，不使登录或工作台崩溃。首次绘制采用正确主题，原生控件和浏览器主题颜色一致。

验收包含系统实时变化、手动覆盖、首屏与刷新、跨标签页同步、禁止存储，以及桌面和 375px 窄屏的气泡、表单和弹窗可读性。
