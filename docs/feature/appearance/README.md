# 界面主题

## 行为与边界

主题切换入口位于“我的账号”的“外观设置”，提供跟随系统、浅色、深色三种外观。登录页与侧栏不提供独立切换入口，所有页面统一使用所选主题。默认跟随系统，系统配色变化即时生效；显式选择优先于系统设置。选择保存在当前浏览器，同源标签页同步，刷新与退出登录后保留，不写入账号或服务器。

首次绘制前应用主题，避免深色偏好下出现浅色闪烁。浏览器禁止存储时仍可在当前页面切换。背景、文字、边框、导航、表单、浮层、通知、转写气泡及原生控件使用一致配色，深色保留蓝色强调色。

## 实现约束

复用现有 CSS 语义变量与根元素 `.dark`；React 主题状态负责监听系统及存储事件，并在卸载时解除监听。head 中的同步初始化负责首屏配色。偏好仅接受 system、light、dark，未知值回退到 system。

## 验收

[切换主题](use-case/change-theme.md)：验证桌面和窄屏入口、系统实时变化、手动覆盖、刷新恢复、跨标签同步及不可用存储。

浏览器标签标题固定为 Voices。主动操作失败通过错误 toast 提醒，同时保留字段或页面中的具体原因；加载与轮询失败在相关区域显示错误和重试入口，不重复弹出通知。用户主动取消或已废弃的请求不弹错误通知。

## 加载与行内编辑

全站初次加载以共用骨架屏和可读状态提示占位；已有内容轮询时保持可读，不反复闪回骨架。明确进行中的提交按钮显示旋转指示与 aria-busy 并禁用重复提交，普通禁用和取消按钮不表示正在提交。动画尊重减少动态效果偏好。

标题、开始时间、备注与片段文字复用 InlineEdit，组件负责草稿、聚焦、键盘、保存状态和错误展示，业务调用方负责校验与版本冲突。编辑开始时绑定当前值与保存回调，轮询不能替换草稿或更新其基准版本。单行 Enter 保存，多行 Ctrl/⌘+Enter 保存，Escape 取消；输入法组合期间不触发快捷键。保存失败保留输入，无修改时关闭且不写入；保存中禁止修改与取消，结束后焦点回到编辑入口。标题使用紧凑的单行编辑区域，多行文本可增高；不把单字段编辑扩成整页表单。

## 信息层级与操作反馈

界面以对象名称、当前状态和下一步操作为主；同一事实不同时在标题、说明、状态徽标和页脚重复显示。格式约束放在字段附近，诊断 ID、内部错误代码与低频解释默认折叠；会影响当前选择的失败原因、删除后果、密码修改后的退出行为和覆盖已有结果提示保持可见。无记录与筛选无匹配分别提示，后者提供清除筛选入口。

同一区域执行操作时，只在实际触发的按钮或控件旁显示忙碌反馈，其余互斥操作禁用但不显示正在执行。失败保留输入并显示具体原因。主动刷新同一列表保留已有内容；录音库、人物及任务列表切换同一账号内的筛选时保留上一组结果并明确提示正在更新，成功后整体替换，失败可重试；切换对象或账号范围立即隔离旧内容。加载更多只在分页入口显示忙碌状态。

读取请求同时支持主动取消与 30 秒超时，超时停止等待并提供重试，不自动重发写入。后台标签暂停定时读取，重新可见时刷新。文字筛选等待约 250ms 输入停顿后查询；旧响应不能覆盖新筛选，分页游标与筛选绑定。

UI 的布局、文案、状态、组件选择与验收规则见 [web/DESIGN.md](../../../web/DESIGN.md)。业务行为仍由各 Feature 与 Use Case 拥有。
