# 界面主题

用户在“我的账号 → 外观设置”选择跟随系统、浅色或深色，所有页面即时采用同一主题，无需提交表单。登录页与侧栏应用当前主题，但不提供独立选择器。

## 行为与边界

默认跟随系统，系统配色变化即时生效；显式选择优先于系统设置。选择保存在当前浏览器，同源标签页同步，刷新与退出登录后保留，不写入账号或服务器。浏览器禁止存储时仍可在当前页面切换。

首次绘制前应用主题，避免深色偏好下出现浅色闪烁。背景、文字、边框、导航、表单、浮层、通知、转写气泡及原生控件使用一致配色，深色使用官方 neutral 配色。

全站使用 shadcn/ui Base UI / nova 官方 neutral 主题与组件默认外观，不维护额外的自定义配色和控件皮肤。手机导航使用官方 Sidebar 的 Sheet，桌面与手机均可用键盘和触摸完成导航与业务操作。
