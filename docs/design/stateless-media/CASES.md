# Cases

1. A 上传成功后删除容器和临时目录，B 能通过同一会话播放并继续任务。
2. 上传中断只留下 writing 对象，租约到期回收；相同文件并发完成仅发布一个录音。
3. Range 跨越块边界、只读最后字节、无效范围，返回正确内容或 416，内存不随文件大小增长。
4. 转码任务失租后晚到发布被拒绝，新执行者从数据库原件重新计算。
5. 删除与读取并发时拒绝新读取，停止既有流，待读租约结束后回收块。
6. PostgreSQL 备份恢复后，无需恢复应用磁盘即可核对音频摘要、人物、版本和任务。

7. 快照时无远端操作记录，快照后已受理；恢复旧数据库后隔离任务，不按旧状态重新提交。
8. 用户暂未查到远端资源但随后到达成功响应；保留操作登记位置，登记后清理。
