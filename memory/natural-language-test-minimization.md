# 自然语言 E2E 与最小低层测试

用户要求让自然语言 E2E 承担主要行为验收，非自然语言测试尽量少。实现遵循 `docs/engineering/delivery/README.md`：先迁移并通过真实页面/Go/PostgreSQL 验收，再删重复断言；不以合并函数或更换中文名称制造比例。

## 实际迁移

所有原有浏览器文件的正常业务动作改为中文 `agent.act`。测试代理仍固定 `gpt-6.1-sol` / OpenAI Responses，dotenv 自动加载根 `.env`，不做模型或定位器降级。文件传输、并发窗口、网络故障和精确结果断言继续由代码控制；被测 STT/LLM/更新服务使用外部 fake。

管理概览/日志、账号筛选/停用从目录流程拆出，各有独立 schema；onboarding 保持三个独立 fixture。录音工作台新增无效语言选择被拒绝且零上传请求、剪贴板权限拒绝后手动复制的真实 UI 验证。模型目录请求每次操作计数为一次。全套现为 12 条独立浏览器场景。

## 删减与承接

- 密码函数正常路径删除；真实注册浏览器使用六位密码。短密码/73 字节超限由注册 API 拒绝，并检查无效注册不消耗 bootstrap。
- 语言注册、资料修改、登录恢复及账号隔离的重复 API 正常路径删除，由语言浏览器承担。保留非法输入、并发修改不同字段、数据库 CHECK、CSRF 与 restore 写保护。
- 账号筛选的普通关键词/角色/状态组合移到独立浏览器场景；API 仅保留 SQL 通配符按字面量处理、非法筛选和越权。
- 管理概览和注册审计正常路径由管理浏览器承担；API 保留同时间戳分页无丢失/重复、日志脱敏、非法查询、日志清理与有界写入。
- 摘要内容和编辑后过期由目录浏览器承担；底层保留拥有权、幂等、跨实例领取、输入快照清理、删除清理及并发/恢复边界。
- 模型目录低层删除排序、空列表、同类非法结构/鉴权/上游失败组合，保留不同处理后果的代表输入。摘要解析移除与详细原因矩阵重复的未知片段、截断案例，共删除 7 个重复协议分支。
- `i18n.test.ts` 删除；翻译键、插值和源码完整性的两项检查迁到 `web/scripts/check-i18n.mjs`，由 `pnpm check:i18n` 和类型检查入口执行。行为翻译由语言浏览器承担。
- 通用成功 202 JSON 解码单测删除；真实目录生成/重试的 202 响应经过生产 HTTP 客户端并由 UI 结果验证。

## 保留低层测试的具体风险

- `accounts`：跨实例首位管理员与最后管理员竞争、已有会话撤销、直接跨账号读写、邮箱/用户名身份归一、登录限流、非法输入绕过 UI。
- `language`：两个并发 PATCH 不能互相覆盖、直接 SQL 不能写非法语言、restore/CSRF 不能绕过。
- `server_settings` / `llm_models` / `onboarding`：原始响应与审计不能泄密；更换地址不能携带旧密钥；并发 revision、在途旧测试不能批准新配置；排队任务快照、迁移及重启配置来源。UI 无法检查秘密是否已从数据库清除。
- `integration` / `large`：跨实例音频范围读取、幂等冲突、上传有界内存、未知远端受理状态、恢复隔离、全局并发/租约、删除与清理不饥饿、原版本与跨版本 FK、人物覆盖/归档历史和本人事务回滚。
- `avatars`：原始图片类型/大小、跨账号访问、revision 冲突和 blob 清理。
- `administration`：原始日志字段泄密、同时间戳分页、限流丢弃计数、restore 中清理及停止生命周期。
- `insights`：重复提交/领取、跨实例、取消与期限、秘密/输入清理、限制、恢复；协议层拒绝模型伪造时间、无效片段/顺序/结构及内容截断，不重试或泄露原文。
- `providers`：两个真实供应商协议的状态/结果差异、创建受理不确定性、取消、重定向凭据隔离、流式有界读、删除受理不等于清理完成、能力拒绝时零请求。
- `persistence`：非空旧数据库迁移后账号与业务数据保留。
- `updates` / Worker / 发布脚本：版本顺序、防降级、缓存过期/失败、并发关闭、请求超时/重定向拒绝、遥测身份/隔离、真实 Worker handler 与发布重入边界。
- 前端 HTTP 边界：CSRF/幂等键/同源与部署前缀、写失败不重发、409 不覆盖、损坏/HTML 响应不泄密、401 鉴权事件、空响应与代理诊断。
- 前端链接边界：可信 public URL 与部署前缀、跨录音/跨版本锚点拒绝、危险鉴权返回地址。页面正常流程不能证明恶意输入被拒绝。

## 验收注意

自然语言动作比定位器慢；不要用“操作结束后片段数还要增加”推断分页成功，应验证最终完整结果。短暂提示须在操作期间观察。待输入的文字用参数明确边界，精确断言不得为代理擅自增删内容放宽。没有修改产品行为。

前端选项函数测试整文件删除，真实导入 UI 验证无效语言失败、保留输入、未发请求，修正后成功转写。链接测试删除普通空正文生成和剪贴板 mock 成败；工作台实际菜单生成转义引用，操作系统剪贴板被拒绝时显示手动复制。保留可信 URL、前缀、锚点拥有权和危险返回地址。人物继承名、TXT 导出编辑文案、配置正常保存标志等重复 API 断言删除，相关生命周期和原始响应/审计脱敏检查保留。

## 2026-10-21 最终验证

- 隔离 PostgreSQL（localhost 临时端口 55439）、真实 Go 应用、系统 Chromium，所有 12 条自然语言 E2E 实际通过。使用项目 `pnpm test:e2e` 中的 Go wrapper，分批 `go test ./internal/app -run ... -count=1 -v` 执行；修正后仅复跑受影响场景。报告位于 `web/.e2e/{accounts,settings,models,updates,language,workbench,insights,administration,account-filters,onboarding/{main,revision,skip}}/summary.md`。
- 其中工作台最终约 300 秒、目录约 238 秒、模型目录含请求计数约 139 秒；不是全套单次 green 命令，不能把早先失败批次记成通过。失败均为测试预期/输入边界/瞬时 UI 时序问题，未通过放宽业务断言或改产品逻辑解决。
- 最终 `TEST_DATABASE_URL=<隔离测试库> pnpm check` 返回 0：Go 所有包、15 项前端测试、10 项更新 Worker 测试、4 项发布检查、Go vet、翻译静态检查、TS 类型检查、前端构建与 Worker 类型检查通过。前端原 24 项：7 项重复行为测试删除，2 项转为独立静态检查，剩 15 项；不把静态迁移算作删除验证能力。
- `concord check --json`、`concord trace gaps --json --fresh`、actionlint、`git diff --check` 完成。trace 仍有既有主题测试关系、账号/无状态代码关系缺口；这是显式关系缺失，不是覆盖率证明。前端构建保留既有大 bundle 警告。
- 不声称已达到 80/20 的用例数量比例。普通用户行为已由自然语言验收；保留的低层边界按上述实际故障分类，而不是删除安全测试凑数。
- PostgreSQL 测试结束只剩 public schema；已停机并删除本轮临时数据库目录。没有本轮 pane/tab/worktree 或浏览器子进程残留。未提交、推送、部署，也没有修改远端 CI secrets；测试代理使用已获授权的真实模型，被测应用外部服务仍 fake。
