# Voices

中文 · [English](README.en.md)

**把每天的录音变成可以阅读、搜索和引用的对话。**

Voices 是一个自托管的录音工作台。拖入会议、访谈或日常录音，它会自动转写并区分说话人，用聊天记录的形式呈现每一句话。你可以随手校正文字、标出谁在说话，并把任意一句话复制成带链接的引用，随时跳回原声。

录音和文字都留在你自己的服务器上。

## 为什么用 Voices

- **拖进去就好**：一次拖入多个文件，上传完成后自动转写，不用逐个设置。重复的文件会被识别，不会重复入库。
- **像读聊天记录一样读录音**：你的发言在右，其他人在左，配姓名和头像。点一下句子就能播放那一句，点文字就能改。
- **认得出谁在说话**：把“说话人 1”关联到人物档案，同一个人跨录音统一管理；还能按人物筛选录音。背景声、音乐和系统提示音可以归类隐藏。
- **一句话就是一个链接**：复制 `[张三: 明天上午讨论方案](链接)` 粘到笔记里，点开直接定位到原句和对应音频。之后改字、重新转写，旧链接也不会失效。
- **改错不怕覆盖**：重新转写生成新版本，旧版本和人工校正都会保留，由你决定采用哪一版。
- **随时导出**：TXT、JSON、SRT 字幕。
- **多语言**：自动检测、单语言或中英混说等多语言模式，支持 [Soniox](https://soniox.com) 与 [AssemblyAI](https://www.assemblyai.com)。
- **适合家人或小团队共用**：每个账号的数据完全独立，管理员也看不到别人的录音。

## 你的数据，你的服务器

- 音频、转写和人物资料全部保存在你自己的 PostgreSQL 中，备份一个数据库就够了。
- 服务商 API key 只保存在服务器端，不会发到浏览器。
- 网络中断时，可能已经被服务商接收的请求不会自动重发，避免重复扣费。
- 应用本身无状态，容器可以随时重建或多开。

## 快速开始

需要 Docker。在项目根目录新建 `.env`：

```sh
POSTGRES_PASSWORD=<随机十六进制字符串>
# 可选，也可以启动后在网页里填写
SONIOX_API_KEY=
```

```sh
docker compose up --build -d
```

打开 <http://localhost:8080>，第一个注册的账号自动成为管理员。之后可以在「服务器管理」里配置转写服务、关闭注册或管理账号。

需要公网访问时，在前面放一个提供 HTTPS 的反向代理，并在首次启动前把 `.env` 中的 `PUBLIC_BASE_URL` 设为实际访问地址；之后在服务器设置里修改。
